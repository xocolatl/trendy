# A0041: recursion with ever larger types

An operator with type parameters is compiled once for each list of types
its calls give them. A call that leads back to the operator making it,
directly or through others, and gives a type parameter a type built from
that operator's own, such as `tuple { x: T }` for `T`, would give it a
larger type each time around: the operator would need a version for each
of infinitely many types.

```trendy,error
operator nest{a: T, b: T}
    types { T: any type }
[
    call nest{a: tuple { x: a }, b: tuple { x: b }};
];

operator main{} [];
```

Pass the type parameters on as they are, or give the call specific types:

```trendy
operator nest{a: T, b: T}
    types { T: any type }
[
    call debug_value{v: tuple { x: a, y: b }};
];

operator main{} [];
```
