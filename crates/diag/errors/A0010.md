# A0010: unknown attribute

A tuple value has an attribute that its declared type doesn't. When the name
is close to an attribute the value is missing, the fix renames it; otherwise
the fix removes it.

```trendy,error
var point: tuple { x: approximate, y: approximate } := tuple { x: 1e0, why: 2e0 };

operator main{} [];
```

```trendy,error
var point: tuple { x: approximate } := tuple { x: 1e0, z: 3e0 };

operator main{} [];
```

The same rules hold for a call's arguments, which are a tuple of the
operator's parameters:

```trendy,error
operator greet{name: text} [];

operator main{} [
    call greet{nam: "Ada"};
];
```

A `replace` gives attributes the operand has new values, so each one it
names must be one of them. A misspelling is fixed to the closest one; when
none of the names exists, the fix is `extend`, which adds attributes:

```trendy,error
var item := tuple { name: "tea", price: 3 };
var doubled := item replace { prise := price * 2 };

operator main{} [];
```

```trendy,error
var item := tuple { name: "tea", price: 3 };
var priced := item replace { total := price * 2 };

operator main{} [];
```

A load orders by attributes of its relation, and a misspelled one is fixed
to the closest:

```trendy,error
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    var by_age: array tuple { name: text, born: integer };
    load by_age from poets order [asc bron];
];
```

Nor can it order by an attribute that the relation it loads has removed:
`remove` before the order leaves it out of the relation. To order by it
and leave it out of the elements, `remove` comes after the order, which
the fix moves it to:

```trendy,error
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    var names: array text;
    load names value from poets remove {born} order [asc born];
];
```

Use only the declared attributes, and `extend` for new ones:

```trendy
var point: tuple { x: approximate, y: approximate } := tuple { x: 1e0, y: 2e0 };
var flat: tuple { x: approximate } := tuple { x: 1e0 };
var item := tuple { name: "tea", price: 3 };
var doubled := item replace { price := price * 2 };
var priced := item extend { total := price * 2 };
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    var by_age: array tuple { name: text, born: integer };
    load by_age from poets order [asc born];
    var names: array text;
    load names value from poets order [asc born] remove {born};
];
```
