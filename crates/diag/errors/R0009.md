# R0009: conflicting changes in an `assign` block

An `assign` block makes its assignments at once: every value is computed
from the variables as they were before it. Several changes to one variable
merge into its new value, if they don't touch the same part of it: if no
two changes to a relation remove the same tuple, which a `delete` or an
`update` selects and an `i_delete` names, no two `update`s of a tuple set
the same attribute, and no two assignments of an array's elements set the
same one, or one an element in the other's, as `grid[1]` and `grid[1][2]`.
When they do, neither order would be the right one, so it is an error.

Which tuples a condition selects is known only when the program runs, so a
conflict between them stops the program, writing `error[R0009]: two changes
in an assign block remove the same tuple` to stderr and exiting with status
1, as two elements' positions known only then do, writing
`error[R0009]: two changes in an assign block set the same element`. Here
both changes remove Kenji's tuple:

```trendy
var rooms := relation { { room: 1, guest: "Kenji" } } key { room };

operator main{} [
    assign {
        update rooms { guest := "Wanjiru" } where room = 1;
        delete rooms where guest = "Kenji";
    };
];
```

A conflict known when compiling is reported then: two `i_delete`s of the
same tuple, two `update`s of the same attribute of a tuple, two
assignments of an element at the same position, or an assignment of a
whole new value, `v := …`, with any other change to `v`:

```trendy,error
var address := tuple { city: "Nairobi", postal_code: "00100" };

operator main{} [
    assign {
        update address { city := "Mombasa" };
        update address { city := "Kisumu", postal_code := "40100" };
    };
];
```

```trendy,error
var count := 0;

operator main{} [
    assign {
        count := count + 1;
        count := count + 2;
    };
];
```

```trendy,error
var grid := array [array [1, 2], array [3, 4]];

operator main{} [
    assign {
        grid[1] := array [0, 0];
        grid[1][2] := 5;
    };
];
```

Make one change do both, or, if one is meant to see the other's result,
make them in two statements, one after the other:

```trendy
var address := tuple { city: "Nairobi", postal_code: "00100" };
var count := 0;
var rooms := relation { { room: 1, guest: "Kenji" } } key { room };
var grid := array [array [1, 2], array [3, 4]];

operator main{} [
    update address { city := "Kisumu", postal_code := "40100" };
    count := count + 3;
    grid[1] := array [0, 5];
    update rooms { guest := "Wanjiru" } where room = 1;
    delete rooms where guest = "Kenji";
];
```
