# P0020: key before the initial value

A relation variable's keys come last in its declaration: after its value,
or after its type when it has no value. A key written before `:=` is moved
after the value by the fix.

```trendy,error
var rivers: relation { name: text, country: text } key { name } := relation {
    { name: "Mekong", country: "Laos" },
    { name: "Volga", country: "Russia" },
};

operator main{} [];
```

Put the keys after the value:

```trendy
var rivers: relation { name: text, country: text } := relation {
    { name: "Mekong", country: "Laos" },
    { name: "Volga", country: "Russia" },
}
key { name };

var lakes: relation { name: text, country: text } key { name };

operator main{} [];
```
