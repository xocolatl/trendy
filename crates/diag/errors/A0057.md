# A0057: an operator with a type's name

A type's name is its selector's: `celsius{degrees: 21.5e0}` is the value
of type `celsius` whose `degrees` are 21.5, as *The Third Manifesto* has
a selector for each possible representation (RM Prescription 4). So no
other operator can have a type's name, whatever its parameters, and a
type can't have the name of an operator, the prelude's included: a call
of that name always selects a value of the type.

```trendy,error
type celsius { { degrees: approximate } };

operator celsius{fahrenheit: approximate}: celsius [
    celsius{degrees: (fahrenheit - 32e0) * 5e0 / 9e0}
];

operator main{} [];
```

```trendy,error
type count { { n: integer } };

operator main{} [];
```

Give the operator, or the type, another name:

```trendy
type celsius { { degrees: approximate } };

operator from_fahrenheit{degrees: approximate}: celsius [
    celsius{degrees: (degrees - 32e0) * 5e0 / 9e0}
];

operator main{} [];
```
