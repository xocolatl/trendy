# A0058: a constraint known when compiling

A type's constraints say which of the values its components could make
are its own, so each is a condition on the components. One whose value is
known when compiling, true or false whatever the components, says
nothing about them:

- one that is always true constrains nothing, and the fix deletes it;
- one that is always false leaves the type no values, so every selection
  of one would fail.

```trendy,error
type percentage {
    { value: integer },
    constraint 0 <= 100,
};

operator main{} [];
```

```trendy,error
type percentage {
    { value: integer },
    constraint 100 < 0,
};

operator main{} [];
```

Write the condition on the components:

```trendy
type percentage {
    { value: integer },
    constraint value >= 0 and value <= 100,
};

operator main{} [];
```
