# A0073: a name more than one unit declares

A name a unit writes means one declaration it sees: one of its own,
which hides any other unit's, so that a unit never qualifies its own
names, or else one of the prelude's interface, which every unit sees, or
of the interface of a unit its section uses. A name more than one of
those other units declares means none of them, as nothing settles which
by order, so it is reported where it is written, with each
declaration. A unit that never writes the name compiles, so a unit that
gains a declaration breaks only the units that write its name. Operators
of one name whose parameters' names differ are overloads, and don't
clash. For the units `lakes/depths.trendy` and `seas/depths.trendy`:

```trendy,unit lakes.depths
interface

type metres { { m: integer } };
```

```trendy,unit seas.depths
interface

type metres { { m: integer } };
```

```trendy,error
uses { lakes.depths, seas.depths };

var depth := metres{m: 281};

operator main{} [];
```

The prelude is one of those other units, so a used unit's declaration of
one of its names clashes with the prelude's where the name is written.
For the unit `tally.trendy`:

```trendy,unit tally
interface

operator count{r: any relation}: integer;

implementation

operator count{r: any relation}: integer [ 0 ];
```

```trendy,error
uses { tally };

var lakes := relation { { name: "Baikal" } };
var n := count{r: lakes};

operator main{} [];
```

Qualify the name by the unit meant, rename one of the declarations, or
use only one of the units where the name is written. A unit's own
declaration of the name hides the others' there:

```trendy
uses { lakes.depths, seas.depths };

var depth := seas.depths::metres{m: 281};

operator shallow{depth: seas.depths::metres}: boolean [ depth.m < 100 ];

operator main{} [];
```

```trendy
uses { lakes.depths };

var depth := metres{m: 281};

operator main{} [];
```

```trendy
uses { lakes.depths };

type metres { { m: integer, deep: boolean } };
var depth := metres{m: 281, deep: false};

operator main{} [];
```
