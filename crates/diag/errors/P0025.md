# P0025: assignments separated by commas

Tutorial D writes a multiple assignment as assignments separated by
commas: `X := Y, Y := X;`. A comma is easy to miss, and changes what the
statement means, so trendy writes assignments made at once in an `assign`
block, each ending with `;`:

```trendy,error
var x := 1;
var y := 2;

operator main{} [
    x := y, y := x;
];
```

The fix puts them in a block, which makes them at once: every value is
computed from the variables as they were before it, so this swaps `x` and
`y`. In a block already, the fix ends each assignment with `;`:

```trendy,error
var x := 1;
var y := 2;

operator main{} [
    assign {
        x := y,
        y := x;
    };
];
```

```trendy
var x := 1;
var y := 2;

operator main{} [
    assign {
        x := y;
        y := x;
    };
];
```

To make the assignments one after the other instead, write them as separate
statements: `x := y; y := x;` sets both to `y`'s value.
