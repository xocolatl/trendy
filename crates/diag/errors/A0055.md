# A0055: an attribute `load_csv` can't read

`load_csv` reads a CSV file's records into an array of tuples, each
attribute the field in the column of its name, read as the attribute's
type: text as it is, and an integer, an approximate number or a boolean
as `parse_integer`, `parse_approximate` and `parse_boolean` read them.
No field writes a value of another type, such as a relation or a tuple,
so an attribute of one is reported:

```trendy,error
operator main{} [
    var rows: array tuple { city: text, districts: relation { district: text } };
    call load_csv{path: "cities.csv", out rows: rows};
];
```

The attributes are the columns to read, so they must be known when
compiling: an array whose tuples' type is a type parameter, whose
attributes each call of its operator gives, is reported too.

```trendy,error
operator read{out rows: array T}
    types { T: any tuple }
[
    call load_csv{path: "cities.csv", out rows: rows};
];

operator main{} [];
```

Load the columns as text, integers, approximate numbers or booleans,
where the array's type is written, and compute the rest from them:

```trendy
operator main{} [
    var rows: array tuple { city: text, district: text };
    call load_csv{path: "districts.csv", out rows: rows};
    var districts: relation { city: text, district: text };
    load districts from rows;
    var cities := districts{city} extend { districts := !!districts };
    call debug_table{r: cities};
];
```
