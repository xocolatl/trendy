# A0055: an attribute `load_csv` can't read

`load_csv` reads a CSV file's records into an array of tuples, each
attribute the field in the column `columns` gives it, read as the
attribute's type: text as it is, and an integer, an approximate number, a boolean or a
character as `parse_integer`, `parse_approximate`, `parse_boolean` and
`parse_character` read them. A value of a type of the program's own is selected from its
components, each read from a column of its own. No field writes a value
of another type, such as a relation or a tuple, so an attribute of one,
or a component, named as `t.c` reads it, is reported:

```trendy,error
uses { trendy.files };

operator main{} [
    var rows: array tuple { city: text, districts: relation { district: text } };
    call load_csv{
        path: "cities.csv",
        header: true,
        columns: tuple { city: 1, districts: 2 },
        out rows: rows,
    };
];
```

The attributes' types say how to read their columns, so they must be
known when compiling: an array whose tuples' type is a type parameter,
whose attributes each call of its operator gives, is reported too.

```trendy,error
uses { trendy.files };

operator read{out rows: array T}
    types { T: any tuple }
[
    call load_csv{path: "cities.csv", header: true, columns: tuple { city: 1 }, out rows: rows};
];

operator main{} [];
```

Load the columns as text, characters, integers, approximate numbers or booleans,
where the array's type is written, and compute the rest from them:

```trendy
uses { trendy.files };

operator main{} [
    var rows: array tuple { city: text, district: text };
    call load_csv{
        path: "districts.csv",
        header: true,
        columns: tuple { city: 1, district: 2 },
        out rows: rows,
    };
    var districts: relation { city: text, district: text };
    load districts from rows;
    var cities := districts{city} extend { districts := !!districts };
    call debug_table{r: cities};
];
```
