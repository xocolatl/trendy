# E0120: name in a tuple or relation value

For now, a tuple or relation value in an operator's body is built when the
program is compiled, so its attributes can't refer to parameters or
variables, whose values are known only when the program runs.

```trendy,error
operator show{n: integer} [
    call debug_value{v: tuple { n: n }};
];

operator main{} [];
```

```trendy,error
var a := 1;

operator main{} [
    call debug_value{v: tuple { x: a }};
];
```

A variable's initial value can refer to other variables, so declare a
variable holding the value, and use it. A parameter can be passed on as it
is:

```trendy
var a := 1;
var point := tuple { x: a };

operator show{n: integer} [
    call debug_value{v: n};
];

operator main{} [
    call debug_value{v: point};
    call show{n: a};
];
```
