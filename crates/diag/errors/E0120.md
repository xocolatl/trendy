# E0120: name in a constant value

For now, a variable's initial value, and the attributes of a tuple or relation
value, can only be literals: they are fixed when the program is compiled. A
call's arguments can be names of variables and parameters.

```trendy,error
var a := 1;
var b := a;

operator main{} [];
```

```trendy,error
var a := 1;

operator main{} [
    call debug_value{v: tuple { x: a }};
];
```

Write the value itself, or pass the name directly as an argument:

```trendy
var a := 1;
var b := 1;

operator main{} [
    call debug_value{v: a};
];
```
