# P0028: conditional written another way

A value that depends on a condition is written
`if condition then value else value`, with the condition first. Another
condition is an `if` in the `else` branch:
`if a then x else if b then y else z`. Other languages write it in other
ways, and each is fixed to trendy's: Python's `a if c else b`, C's
`c ? a : b`, Python's `elif`, Perl's `elsif` and others' `elseif` for
`else if`, and Tutorial D's `END IF` after the last value, which an `if`
doesn't have, since its `else` branch ends it.

```trendy,error
operator label{n: integer}: text [
    return "one" if n = 1 else "many";
];

operator main{} [];
```

```trendy,error
operator label{n: integer}: text [
    return n = 1 ? "one" : "many";
];

operator main{} [];
```

```trendy,error
operator label{n: integer}: text [
    return if n = 1 then "one" elif n = 2 then "two" else "many";
];

operator main{} [];
```

```trendy,error
operator label{n: integer}: text [
    return if n = 1 then "one" else "many" end if;
];

operator main{} [];
```

Write the condition first:

```trendy
operator label{n: integer}: text [
    return if n = 1 then "one" else if n = 2 then "two" else "many";
];

operator main{} [];
```
