# A0008: attribute defined more than once

The attributes of a tuple type, or of a tuple value, must have distinct names.
A tuple's heading is a set of attributes, so each name can appear only once.

```trendy,error
var point: tuple { x: approximate, x: approximate };

operator main{} [];
```

```trendy,error
var point := tuple { x: 1e0, x: 2e0 };

operator main{} [];
```

The same rules hold for a call's arguments, which are a tuple of the
operator's parameters:

```trendy,error
operator greet{name: text} [];

operator main{} [
    call greet{name: "Ada", name: "Edgar"};
];
```

In a `group` or a `wrap`, each attribute goes into one grouping or
wrapping; in a `group`, the attributes no grouping names are the ones each
group shares:

```trendy,error
var births := relation { { name: "Ada", born: 1815, place: "London" } };
var by_place := births group { names := {name}, people := {name, born} };

operator main{} [];
```

A load's order names each attribute once, and a type's order each
component, of which a type has one: an item orders only the tuples, or
the values, equal on the items before it, so a repeat orders nothing, and
the fix
removes it.

```trendy,error
var births := relation { { name: "Ada", born: 1815, place: "London" } };

operator main{} [
    var by_age: array tuple { name: text, born: integer, place: text };
    load by_age from births order [asc born, asc name, desc born];
];
```

A type's possible representations' components are read by name, as
`v.c`, so a component's name says which representation it is of, and no
two have one. A subtype defined by constraints can have its supertype's
component in a representation of its own if both its conversions carry it
unchanged, `ctr := ctr`, since it is then the same one:

```trendy,error
type ellipse { { a: approximate, b: approximate, ctr: integer }, constraint a >= b };
type circle is ellipse {
    constraint a = b,
    { r: approximate, ctr: integer } to { a := r, b := r, ctr := ctr + 1 } from { r := a, ctr := ctr - 1 },
};

operator main{} [];
```

Rename or remove the duplicate, or carry the component unchanged:

```trendy
var point: tuple { x: approximate, y: approximate };
var other := tuple { x: 1e0, y: 2e0 };
var births := relation { { name: "Ada", born: 1815, place: "London" } };
var by_place := births group { names := {name}, years := {born} };

operator main{} [
    var by_age: array tuple { name: text, born: integer, place: text };
    load by_age from births order [asc born, asc name];
];
```

```trendy
type ellipse { { a: approximate, b: approximate, ctr: integer }, constraint a >= b };
type circle is ellipse {
    constraint a = b,
    { r: approximate, ctr: integer } to { a := r, b := r, ctr := ctr } from { r := a, ctr := ctr },
};

operator main{} [];
```
