# A0008: attribute defined more than once

The attributes of a tuple type, or of a tuple value, must have distinct names.
A tuple's heading is a set of attributes, so each name can appear only once.

```trendy,error
var point: tuple { x: rational, x: rational };

operator main{} [];
```

```trendy,error
var point := tuple { x: 1.0, x: 2.0 };

operator main{} [];
```

The same rules hold for a call's arguments, which are a tuple of the
operator's parameters:

```trendy,error
operator greet{name: text} [];

operator main{} [
    call greet{name: "Ada", name: "Edgar"};
];
```

Rename or remove the duplicate:

```trendy
var point: tuple { x: rational, y: rational };
var other := tuple { x: 1.0, y: 2.0 };

operator main{} [];
```
