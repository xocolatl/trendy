# A0080: a constant without a value

A constant is a name for a value that never changes, so it has that value from
where it is declared, and nothing can give it one later: `const name[: type] :=
value;`. Only a variable can start with its type's default, as it can be assigned
after.

```trendy,error
operator main{} [
    const limit: integer;
    call debug_value{v: limit};
];
```

An interface can leave a constant's value to its unit's implementation, so that
other units see only its type, and nothing of how it is computed. That takes its
type, in the interface, and its value, in the implementation:

```trendy,error
interface

const size;

implementation

const size := 12;

operator main{} [];
```

Give it its value, or, if it is to change, declare a variable:

```trendy
operator main{} [
    const limit: integer := 10;
    var count: integer;
    count := limit + 1;
    call debug_value{v: count};
];
```

```trendy
interface

const size: integer;

implementation

const size := 12;

operator main{} [];
```
