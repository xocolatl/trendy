# A0056: arguments that choose no operator

Operators of one name are told apart by their parameters' names, which
every call names its arguments with, so a call calls the operator whose
parameters its arguments name. A call whose arguments' names are those
of none of them is checked against the one they name most nearly, whose
missing and unknown arguments are reported (A0009, A0010). When two or
more are equally near, nothing says which was meant, so the call is
reported, with the operators it could be:

```trendy,error
operator greeting{name: text, title: text}: text [ title || " " || name ];
operator greeting{name: text, nickname: text}: text [ nickname ];

operator main{} [
    call debug_value{v: greeting{name: "Ada"}};
];
```

Name the arguments as one of them has its parameters:

```trendy
operator greeting{name: text, title: text}: text [ title || " " || name ];
operator greeting{name: text, nickname: text}: text [ nickname ];

operator main{} [
    call debug_value{v: greeting{name: "Lovelace", title: "Countess"}};
    call debug_value{v: greeting{name: "Ada", nickname: "Enchantress of Numbers"}};
];
```
