# P0030: a load's order

A load gives an array a relation's tuples in an order, which it lists in
brackets after `order`: each item an attribute, after its direction, `asc`
or `desc`, as in `load a from r order [desc born, asc name];`. A
relation's tuples have no order of their own, so the order is always
written, and each item says which way it goes.

SQL's `ORDER BY name DESC`, with its directions after the attributes, its
items without brackets, and its `NULLS FIRST` and `NULLS LAST`, which
there are no nulls for; LINQ's `descending`; an item without a direction;
a load without `from`; and a load into an array without an order, are
reported. So is an ordering written as an assignment's value: a relation
is put in order only by a load, which isn't written as an assignment,
since that would convert a relation into an array implicitly (*The Third
Manifesto*, chapter 5). Tutorial D's `ORDER ( … )` is P0003, and its
capitals P0010. A load into a relation, `load r from a`, has no order,
as a relation's tuples have none; Postgres's `WITH ORDINALITY AS n`,
for the position of each element of the array it loads, is fixed to
`numbered n`.

After the order, `remove {x}` or `keep {x}` says which attributes the
elements leave out, or keep, once the tuples are ordered. Other words for
them are fixed: `drop`, as SAS, Stata and pandas write it, to `remove`;
SQL's `select`, the algebra's `project`, and braces alone, as a
projection is written, to `keep`. A load has one of these lists at most.

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var by_age: array tuple { name: text, born: integer };
    load by_age from poets order by born, name desc nulls last;
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names value from poets order [asc born] select {name};
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    names := poets{name} order [asc name];
];
```

```trendy,error
operator main{} [
    var names := array ["Ada", "Bashō"];
    var positions: relation { name: text, n: integer };
    load positions from names as name with ordinality as n;
];
```

Write the items in brackets, each after its direction, and an element's
position after `numbered`:

```trendy
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var by_age: array tuple { name: text, born: integer };
    load by_age from poets order [asc born, desc name];
    var names: array text;
    load names value from poets{name} order [asc name];
    var youngest_first: array text;
    load youngest_first value from poets order [desc born] keep {name};
    var positions: relation { name: text, n: integer };
    load positions from names as name numbered n;
];
```
