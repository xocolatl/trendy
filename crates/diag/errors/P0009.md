# P0009: invalid rational literal

A rational literal is written in decimal, with digits on both sides of the
decimal point, an exponent, or both: `0.5`, `17.0`, `1e10`, `1.5e-3`. The
exponent starts with `e` or `E`, and its sign is optional. Digit separators
(`1_000.5`) are not supported, and neither are a bare leading or trailing
point (`.5`, `5.`). When the intended number is clear, the fix rewrites the
literal.

```trendy,error
var half: rational := .5;

operator main{} [];
```

```trendy,error
var five: rational := 5.;

operator main{} [];
```

Write digits on both sides of the point:

```trendy
var half: rational := 0.5;
var five: rational := 5.0;

operator main{} [];
```
