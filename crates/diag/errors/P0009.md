# P0009: invalid approximate literal

An approximate literal always has an exponent, which starts with `e` or `E`
and has an optional sign: `1e0`, `2.5e0`, `1e10`, `1.5e-3`. Its decimal
point is optional, with digits on both sides of it. Digit separators
(`1_000.5e0`) are not supported, and neither is a bare leading or trailing
point (`.5`, `5.`).

A decimal number without an exponent, such as `2.5`, is not an approximate
literal: it is reserved for exact numbers, which `approximate` isn't, since
most decimal fractions, such as `1e-1`, have no exact binary
representation. Writing the exponent shows that the value is approximate.
When the intended number is clear, the fix rewrites the literal.

```trendy,error
var half: approximate := 0.5;

operator main{} [];
```

```trendy,error
var half: approximate := .5;

operator main{} [];
```

```trendy,error
var five: approximate := 5.;

operator main{} [];
```

Write an exponent, and digits on both sides of any point:

```trendy
var half: approximate := 0.5e0;
var five: approximate := 5e0;

operator main{} [];
```
