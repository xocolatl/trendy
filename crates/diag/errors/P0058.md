# P0058: a qualified name's form

A name another unit declares can be qualified by that unit's name, then
`::`, as `lakes.depths::metres` is the type `metres` of the unit
`lakes/depths.trendy`. The unit's name has its parts between `.`s, as a
`uses` writes it, and `::` comes once, before the name, so Rust's and
C++'s `::` between the unit's parts is fixed to `.`, and where a type
goes, Java's and Python's `.` before the name, which can mean nothing
else there, is fixed to `::`. For the unit `lakes/depths.trendy`:

```trendy,unit lakes.depths
interface

type metres { { m: integer } };
```

```trendy,error
uses { lakes.depths };

var depth: lakes::depths::metres := metres{m: 281};

operator main{} [];
```

```trendy,error
uses { lakes.depths };

var depth: lakes.depths.metres := metres{m: 281};

operator main{} [];
```

Write the unit's name with `.`s, and `::` before the name:

```trendy
uses { lakes.depths };

var depth: lakes.depths::metres := metres{m: 281};

operator main{} [];
```
