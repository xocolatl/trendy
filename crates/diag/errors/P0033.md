# P0033: a heading declared as a type

A heading's declaration, `heading name := { attribute: type, … };`, lists
the attributes it names, without `relation` or `tuple` before them. A
heading is the attributes of tuples and relations alike, so one
declaration gives both of their types: `relation name` and `tuple name`.

```trendy,error
heading city := relation { name: text, country: text };

operator main{} [];
```

Delete the word, and write it where the heading is used:

```trendy
heading city := { name: text, country: text };

var capitals: relation city := relation city {};

operator main{} [];
```
