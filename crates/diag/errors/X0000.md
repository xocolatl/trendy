# X0000: internal compiler error

The compiler, or the runtime it links into every program, found itself in a
state that should be impossible. This is a bug in trendy, never a mistake in
the program being compiled, and nothing in the program needs to change to
work around it, though a different but equivalent program might avoid it.

The message after the code says what went wrong. Please report it, with the
program that caused it, so the bug can be fixed.
