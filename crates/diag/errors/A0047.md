# A0047: a load that can't fill its array

A load gives an array a relation's tuples, or their values, in order. The
array's elements say which:

- an array of tuples takes the tuples of a relation of their heading;
- an array of other values takes the values of a relation of one
  attribute, of their type, such as a projection onto it.

So the variable loaded is an array: a relation variable is assigned a
relation with `:=`, which the fix writes. An array of values loaded from a
relation of more than one attribute is fixed to load the projection onto
the attribute of their type, when the order names it alone; ordered by
another, the tuples are needed.

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names from poets order [asc name];
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var others: relation { name: text, born: integer };
    load others from poets order [asc name];
];
```

Load the values of a relation of one attribute, and assign a relation:

```trendy
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names from poets{name} order [asc name];
    var others: relation { name: text, born: integer };
    others := poets;
];
```
