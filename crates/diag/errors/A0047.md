# A0047: a load that can't fill its array

A load gives an array a relation's tuples, or the values of its only
attribute, in order, and says which:

- `load a from r` gives an array of tuples the tuples of a relation of
  their heading;
- `load a value from r` gives an array the values of a relation of one
  attribute, of their type, such as a projection onto it, as `value from
  r` is the value of a relation's only tuple's only attribute.

An array of tuples and an array of their values are different types, so
nothing converts one into the other unless the load says so (TTM,
chapter 3). A load into an array of values without `value` is fixed to
have it, and, from a relation of more than one attribute, to load the
projection onto the attribute of their type, when the order names it
alone; ordered by another, the tuples are needed. `value` in a load
whose array's elements are the relation's tuples is fixed away.

The variable loaded is an array: a relation variable is assigned a
relation with `:=`, which the fix writes.

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names from poets{name} order [asc name];
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names value from poets order [asc name];
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var others: relation { name: text, born: integer };
    load others from poets order [asc name];
];
```

Load the values of a relation of one attribute, with `value`, and assign
a relation:

```trendy
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names value from poets{name} order [asc name];
    var by_age: array tuple { name: text, born: integer };
    load by_age from poets order [asc born];
    var others: relation { name: text, born: integer };
    others := poets;
];
```
