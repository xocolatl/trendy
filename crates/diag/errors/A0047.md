# A0047: a load that can't fill its variable

A load gives an array a relation's tuples, or the values of its only
attribute, in order, and says which:

- `load a from r` gives an array of tuples the tuples of a relation of
  their heading;
- `load a value from r` gives an array the values of a relation of one
  attribute, of their type, such as a projection onto it, as `value from
  r` is the value of a relation's only tuple's only attribute.

`remove {x}` after the order leaves attributes out of the elements, once
the tuples are ordered, and `keep {x}` leaves out all the others, so the
relation needs only the elements' attributes, or the one of the values,
besides those left out. Leaving out the wrong ones is reported too, and
a relation with more attributes than the elements is fixed to leave the
others out, with whichever of `remove` and `keep` names fewer.

An array of tuples and an array of their values are different types, so
nothing converts one into the other unless the load says so (TTM,
chapter 3). A load into an array of values without `value` is fixed to
have it, and, from a relation of more than one attribute, to load the
projection onto the attribute of their type, when the order names it
alone; ordered by another, the tuples are needed. `value` in a load
whose array's elements are the relation's tuples is fixed away.

A load also gives a relation the elements of an array, `load r from a`:
an array of tuples their tuples, and any other array, with `as x`, a
tuple for each element, whose attribute `x` it is; `numbered n` adds `n`,
the element's position, counting from 1. The relation's heading must be
the tuples', and an array of values without `as` is reported, each with
a fix that writes `as` and `numbered` as the heading needs, when only
one way fits it.

The clauses are each for one of the two: `value` and an order for a load
into an array, `as` and `numbered` for a load into a relation, and each
in the other is fixed away. The variable loaded is an array or a
relation, and the value it is loaded from the other: a relation
variable is assigned a relation with `:=`, which the fix writes.

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names from poets{name} order [asc name];
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names value from poets order [asc name];
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var others: relation { name: text, born: integer };
    load others from poets order [asc name];
];
```

```trendy,error
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var named: array tuple { name: text };
    load named from poets order [asc born] remove {name};
];
```

```trendy,error
operator main{} [
    var texts := array ["Nile", "Niger"];
    var rivers: relation { river: text, n: integer };
    load rivers from texts;
];
```

```trendy,error
operator main{} [
    var texts := array ["Nile", "Niger"];
    var rivers: relation { river: text };
    load rivers from texts as river order [asc river];
];
```

Load the values of a relation of one attribute, with `value`, name the
attributes an array's elements make, and assign a relation:

```trendy
var poets := relation { { name: "Ada", born: 1815 }, { name: "Bashō", born: 1644 } };

operator main{} [
    var names: array text;
    load names value from poets{name} order [asc name];
    var by_age: array tuple { name: text, born: integer };
    load by_age from poets order [asc born];
    var named: array tuple { name: text };
    load named from poets order [asc born] remove {born};
    var others: relation { name: text, born: integer };
    others := poets;
    var texts := array ["Nile", "Niger"];
    var rivers: relation { river: text, n: integer };
    load rivers from texts as river numbered n;
];
```
