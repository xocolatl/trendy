# P0024: an `update`'s new values after `where`

An `update` names the variable, then its new attribute values, in braces,
then, for a relation, `where` and the condition that picks the tuples to
change: `update r { a := x } where p;`. Tutorial D writes the values last,
in parentheses, as `UPDATE R WHERE P ( A := X )`.

```trendy,error
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    update poets where name = "Ada" (born := 1816);
];
```

The fix moves the values before `where`, in braces:

```trendy
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    update poets { born := 1816 } where name = "Ada";
];
```
