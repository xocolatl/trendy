# A0002: no `main` operator

Every program needs an operator named `main`, which is where execution starts.
Names are case-sensitive, so `Main` is not `main`.

```trendy,error
operator start{} [];
```

Add a `main` operator, or rename the operator that should be the entry point:

```trendy
operator start{} [];

operator main{} [];
```

A unit is for something: it has `main`, where a program starts, or an interface that
declares what other units see of it, or both. With neither, nothing can run it or use
it, so a unit that is used needs an interface:

```trendy,unit helper
operator greeting{}: text [
    "Karibu"
];
```

```trendy,error
uses { helper };

operator main{} [
    call debug_value{v: greeting{}};
];
```

Write `interface` before what other units should see, each operator by its heading
alone, and `implementation` before its body:

```trendy,unit helper
interface

operator greeting{}: text;

implementation

operator greeting{}: text [
    "Karibu"
];
```

```trendy
uses { helper };

operator main{} [
    call debug_value{v: greeting{}};
];
```

`trendyc` makes a program, so a unit with an interface and no `main` can't be built on
its own, though nothing is wrong with it. Compile a program that uses it, or check it
alone with `trendyc --check`, which is what the language server does:

```trendy,error
interface

operator greeting{}: text;

implementation

operator greeting{}: text [
    "Karibu"
];
```
