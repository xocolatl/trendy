# E0124: operator applied to the wrong numeric type

The arithmetic operators `+`, `-` and `*` take two integers or two
rationals. The others are specific to one type:

- `/` divides rationals;
- `div` divides integers, truncating toward zero;
- `mod` is the remainder of `div`, of integers.

Values never convert to another type implicitly, so `/` can't divide
integers, and `div` can't divide rationals. The fix replaces the operator
with the one for the operands' type.

```trendy,error
var half := 7 / 2;

operator main{} [];
```

```trendy,error
var half := 7.0 div 2.0;

operator main{} [];
```

Use the operator for the operands' type, or write the operands as the other
type:

```trendy
var truncated := 7 div 2;
var half := 7.0 / 2.0;

operator main{} [];
```
