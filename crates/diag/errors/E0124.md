# E0124: operator applied to the wrong type

The arithmetic operators `+`, `-` and `*` take two integers or two
rationals. The others are specific to one type:

- `/` divides rationals;
- `div` divides integers, truncating toward zero;
- `mod` is the remainder of `div`, of integers;
- `||` concatenates text;
- `<`, `<=`, `>` and `>=` order booleans, integers, rationals and text.
  Tuples and relations have no order; they only have `=` and `<>`.

Values never convert to another type implicitly, so `/` can't divide
integers, `div` can't divide rationals, and `+` can't concatenate text.
Where another operator does what was meant, the fix replaces the operator
with it: `div` for `/` on integers, `/` for `div` on rationals, `||` for
`+` on text, and `or` for `||` on booleans.

```trendy,error
var half := 7 / 2;

operator main{} [];
```

```trendy,error
var half := 7.0 div 2.0;

operator main{} [];
```

```trendy,error
var greeting := "hello, " + "world";

operator main{} [];
```

Use the operator for the operands' type, or write the operands as the other
type:

```trendy
var truncated := 7 div 2;
var half := 7.0 / 2.0;
var greeting := "hello, " || "world";

operator main{} [];
```
