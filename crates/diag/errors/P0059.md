# P0059: another language's assertion

C's, Java's, Python's and Rust's `assert`, and Kotlin's and Solidity's
`require`, aren't statements in trendy, which says the same two things in two
other ways. What an operator's arguments must be goes in its braces, where its
callers see it, and each call checks it first. What its body has computed is
checked with an `if` statement and a `fail` statement:

```trendy,error
operator half{n: integer}: integer [
    assert n >= 0;
    n div 2
];

operator main{} [];
```

```trendy
operator half{n: integer, constraint n >= 0}: integer [
    n div 2
];

operator digits{n: integer}: integer [
    var left := n;
    var count := 0;
    while left > 0 loop [
        left := left div 10;
        count := count + 1;
    ];
    if count > 19 then [
        fail failure{message: "more digits than an integer has"};
    ];
    count
];

operator main{} [
    call debug_value{v: half{n: 7}};
    call debug_value{v: digits{n: 123}};
];
```
