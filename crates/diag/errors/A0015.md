# A0015: unknown name

A name refers to no parameter, variable or operator in scope. Inside an
operator, a name is looked up first among the operator's parameters, then
among the program's variables; a call's operator is looked up among the
operators, including the built-ins. When a defined name is close, the fix
replaces it.

```trendy,error
var count := 1;

operator main{} [
    call debug_value{v: cout};
];
```

```trendy,error
operator main{} [
    call debug_valu{v: 1};
];
```

A mean, as SQL's `AVG` or a `mean` elsewhere, is no operator of the
prelude's yet, since the mean of integers isn't an integer; the error says
to divide `sum` by `count`, converting with `to_approximate`:

```trendy,error
var harvests := relation { { crop: "wheat", tonnes: 950 }, { crop: "tea", tonnes: 120 } };
var mean := avg{r: harvests, of: tonnes};

operator main{} [];
```

Use a defined name:

```trendy
var count := 1;
var harvests := relation { { crop: "wheat", tonnes: 950 }, { crop: "tea", tonnes: 120 } };
var mean := to_approximate{from: sum{r: harvests, of: tonnes}} / to_approximate{from: count{r: harvests}};

operator main{} [
    call debug_value{v: count};
];
```
