# A0017: not an operator

`call`, or a call in an expression, `x{name: value}`, names something that
isn't an operator, such as a variable or a parameter. `call` invokes an
update operator: one of the program's own operators, or a built-in such as
`debug_value`; a read-only operator's call is a value, in an expression.

```trendy,error
var greet := "hello";

operator main{} [
    call greet{};
];
```

Call an operator, passing the value as an argument:

```trendy
var greet := "hello";

operator main{} [
    call debug_value{v: greet};
];
```
