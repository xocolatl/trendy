# A0065: a subtype defined by a constraint

A subtype of a type with possible representations is defined by its
specialization constraints, conditions on the supertype's components: its
values are those of the supertype they are true of, as a circle is an
ellipse whose semiaxes are equal (*Type Inheritance and Relational
Theory*, IM Prescription 10). Selecting an ellipse whose semiaxes are
equal gives a circle, and changing a circle's semiaxes so that they
aren't gives just an ellipse:

```trendy
type ellipse { { a: approximate, b: approximate }, constraint a >= b };
type circle is ellipse { constraint a = b };

var round := ellipse{a: 2e0, b: 2e0};
var is_round := round is circle;

operator main{} [
    call debug_value{v: is_round};
];
```

So it needs a constraint, which says which of the supertype's values are
its own. Its values are the supertype's, stored as their components, and
a possible representation of its own, converted to and from them, isn't
in trendy yet:

```trendy,error
type ellipse { { a: approximate, b: approximate }, constraint a >= b };
type circle is ellipse { { r: approximate } };

operator main{} [];
```

Its values are ordered as the supertype's are, so it has no order of its
own:

```trendy,error
type ellipse { { a: approximate, b: approximate }, constraint a >= b, order [asc a, asc b] };
type circle is ellipse { constraint a = b, order [asc a] };

operator main{} [];
```
