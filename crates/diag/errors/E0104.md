# E0104: mismatched types

A variable's initial value must have the variable's declared type. Integer
literals have type `integer`, rational literals (with a decimal point or an
exponent) have type `rational`, and text literals have type `text`. As *The
Third Manifesto* requires, no value converts to another type implicitly, not
even an integer to a rational.

```trendy,error
var count: integer := "5";

operator main{} [];
```

```trendy,error
var name: text := 5;

operator main{} [];
```

```trendy,error
var ratio: rational := 1;

operator main{} [];
```

Write a value of the declared type:

```trendy
var count: integer := 5;
var name: text := "5";
var ratio: rational := 1.0;

operator main{} [];
```
