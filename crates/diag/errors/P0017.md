# P0017: keyword used as a name

Keywords, such as `group`, `tuple` and `not`, have a meaning of their
own, so they can't name anything a program declares: a variable, an operator, a
type, a heading, a parameter or an attribute. Keywords are lowercase, so a name in
another case, such as `Group`, is fine, but easy to confuse with the keyword.

It is reported once for each keyword, where it is first declared, and the fix renames
it there and wherever it is used as a name, and not where it is used as the keyword:

```trendy,error
var remove := 1;

operator main{} [];
```

```trendy,error
heading group := { id: integer, name: text };

var groups: relation group;

operator main{} [];
```

Choose another name, and use it wherever the keyword was used as one:

```trendy
var removed := 1;

heading team := { id: integer, name: text };

var groups: relation team;

operator main{} [];
```
