# P0017: keyword used as a name

Keywords, such as `remove`, `tuple` and `not`, have a meaning of their
own, so they can't name a variable or an operator. Keywords are lowercase,
so a name in another case, such as `Remove`, is fine, but easy to confuse
with the keyword.

```trendy,error
var remove := 1;

operator main{} [];
```

Choose another name, and use it wherever the keyword was used as one:

```trendy
var removed := 1;

operator main{} [];
```
