# A0001: name defined more than once

Two top-level definitions in the same namespace have the same name.
Operators have a namespace of their own, and so do values, which are
variables and parameters, and types. So no two operators can have the same
name, nor two variables, but a variable can have an operator's name, or a
type's. The error points at the second definition and notes where the first
one is.

```trendy,error
operator main{} [];

operator main{} [];
```

```trendy,error
var tally: integer := 0;
var tally := 1;

operator main{} [];
```

Inside an operator, its own names, its parameters' and its local
variables', each mean one thing wherever they are in scope, so no local
variable can have a parameter's name, or that of another local variable
in scope, in its block or one around it; blocks side by side, as an `if`
statement's, can each have one of a name. A second declaration of a local
variable, as Rust gives a variable a new value, is fixed to an assignment
of the first, if the first is declared before it:

```trendy,error
operator scale{n: integer} [
    var n := n * 2;
];

operator main{} [];
```

```trendy,error
operator visit{} [
    var seen := 1;
    var seen := seen + 1;
    call debug_value{v: seen};
];

operator main{} [];
```

```trendy,error
operator visit{n: integer} [
    var seen := 1;
    if n > 0 then [
        var seen := 2;
        call debug_value{v: seen};
    ];
];

operator main{} [];
```

A value block's local variables are its own, and hide no name around it
either: a parameter's, a local variable's, or an attribute of the tuple at
hand's, in an `extend`'s values:

```trendy,error
operator scale{n: integer}: integer [
    [
        var n := 2;
        n * n
    ]
];

operator main{} [];
```

Delete the duplicate, or rename one of the definitions. A variable and an
operator can share a name, and a local variable can have a variable of the
program's name, which it hides:

```trendy
var tally: integer := 0;
var tallied := 1;

operator tally{} [];

operator scale{n: integer} [
    var scaled := n * 2;
    var tallied := scaled + 1;
    call debug_value{v: tallied};
];

operator report{n: integer} [
    if n > 0 then [
        var note := "positive";
        call debug_value{v: note};
    ] else [
        var note := "not positive";
        call debug_value{v: note};
    ];
];

operator main{} [];
```
