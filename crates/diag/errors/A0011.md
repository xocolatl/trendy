# A0011: unknown relation heading

A relation value's heading, the names and types of its attributes, must be
known. It comes from the selector's own heading, from the relation's tuples,
or from the type expected of the value, such as the declared type of the
variable it initializes. An empty `relation {}` with none of these has no
heading.

```trendy,error
var r := relation {};

operator main{} [];
```

Write the heading in the selector, or declare the variable's type:

```trendy
var r := relation { name: text } {};
var s: relation { name: text } := relation {};

operator main{} [];
```
