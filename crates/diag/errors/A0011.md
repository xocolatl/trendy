# A0011: unknown type of an empty value or a failure

An empty relation's heading, the names and types of its attributes, must
be known, as must an empty array's elements' type. A relation's heading
comes from the selector's own heading, from the relation's tuples, or from
the type expected of the value, such as the declared type of the variable
it initializes, another tuple's of the relation it is in, or another
operand's of an operator whose operands have one heading, such as `union`
or `=`, whichever comes first. An array's elements' type comes the same
way, from the selector's own, as in `array text []`, from its elements, or
from the type expected of it. An empty `relation {}` or `array []` with
none of these has no type, nor does a relation joined to another relation,
whose heading it needn't share.

```trendy,error
var r := relation {};

operator main{} [];
```

```trendy,error
var poets := relation { { name: "Ada" } };
var r := relation {} join poets;

operator main{} [];
```

```trendy,error
var rainy := array [];

operator main{} [];
```

A `fail` has no value, as the program fails there, so its type is the one
expected where it is, as an empty relation's heading is: a declared
type's, an operator's result type, or the other branch's of an `if`. One
with none of these has no type:

```trendy,error
var never := fail failure{message: "never"};

operator main{} [];
```

Write the heading or the elements' type in the selector, or declare the
variable's type, or fail in a branch of an `if` whose other branch has a
value:

```trendy
var r := relation { name: text } {};
var s: relation { name: text } := relation {};
var poets := relation { { name: "Ada" } };
var none := relation {} union poets;
var teams := relation { { members: relation {} }, { members: poets } };
var rainy := array text [];
var dry: array text := array [];
var cities := relation {
    { city: "Cairo", rainy: array [] },
    { city: "Mumbai", rainy: array ["Jun", "Jul", "Aug", "Sep"] },
};

operator wettest{months: array text}: text [
    if length{a: months} > 0 then months[1] else fail failure{message: "no months"}
];

operator main{} [];
```
