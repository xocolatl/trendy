# A0011: unknown relation heading

A relation value's heading, the names and types of its attributes, must be
known. It comes from the selector's own heading, from the relation's tuples,
or from the type expected of the value, such as the declared type of the
variable it initializes, another tuple's of the relation it is in, or
another operand's of an operator whose operands have one heading, such as
`union` or `=`, whichever comes first. An empty `relation {}` with none of
these has no heading, nor does one joined to another relation, whose
heading it needn't share.

```trendy,error
var r := relation {};

operator main{} [];
```

```trendy,error
var poets := relation { { name: "Ada" } };
var r := relation {} join poets;

operator main{} [];
```

Write the heading in the selector, or declare the variable's type:

```trendy
var r := relation { name: text } {};
var s: relation { name: text } := relation {};
var poets := relation { { name: "Ada" } };
var none := relation {} union poets;
var teams := relation { { members: relation {} }, { members: poets } };

operator main{} [];
```
