# A0039: type parameter used only once

A type parameter's name is for saying that several types are the same:
that two parameters take arguments of one type, or that the result has
the type of an argument. One written only once, as a parameter's type,
says nothing of the sort, so it is written as what it can be, `any type`,
`any tuple` or `any relation`, in its place, and isn't declared.

```trendy,error
operator show{v: T}
    types { T: any type }
[
    call debug_value{v: v};
];

operator main{} [];
```

```trendy
operator show{v: any type} [
    call debug_value{v: v};
];

operator same{a: T, b: T}: boolean
    types { T: any type }
[
    return a = b;
];

operator main{} [];
```
