# A0040: type parameter declared as a specific type

A type parameter stands for any type of what it says, which each call
gives it from its arguments: `any type`, `any tuple` or `any relation`. A
specific type is written as it is, where it's used, rather than declared.

```trendy,error
operator same{a: T, b: T}: boolean
    types { T: integer }
[
    return a = b;
];

operator main{} [];
```

```trendy
operator same{a: T, b: T}: boolean
    types { T: any type }
[
    return a = b;
];

operator same_number{a: integer, b: integer}: boolean [
    return a = b;
];

operator main{} [];
```
