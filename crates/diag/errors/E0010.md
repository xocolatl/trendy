# E0010: boolean literal in the wrong case

The boolean literals are `true` and `false`, in lowercase. Keywords are
case-sensitive, so the spellings used by Python (`True`) and by SQL and
Tutorial D (`TRUE`) are not boolean literals in trendy.

```trendy,error
var done: boolean := False;

operator main{} [];
```

```trendy,error
var ready := TRUE;

operator main{} [];
```

Write the literal in lowercase:

```trendy
var done: boolean := false;
var ready := true;

operator main{} [];
```
