# A0071: a `uses` after a declaration, or a second in a section

A section's `uses` comes before its declarations, once, so that what they
see is said at its top. The interface and the implementation each have
their own. For the units `lakes/depths.trendy` and `lakes/names.trendy`:

```trendy,unit lakes.depths
interface

heading lake := { name: text, depth: integer };
```

```trendy,unit lakes.names
interface

heading name := { name: text, native: text };
```

a program uses them so:

```trendy
uses { lakes.depths, lakes.names };

operator main{} [];
```

A `uses` after a declaration of its section is moved before the first,
with the comments just before it:

```trendy,error
operator main{} [];

/* What the lakes are. */
uses { lakes.depths };
```

A second `uses` in a section is removed, and the units it names that the
first doesn't are added to the first's:

```trendy,error
uses { lakes.depths };
uses { lakes.names, lakes.depths };

operator main{} [];
```
