# E0007: invalid escape sequence

A backslash in a text literal starts an escape sequence. The valid escapes are
`\"` (quote), `\\` (backslash), `\n` (line feed), `\r` (carriage return),
`\t` (tab), `\0` (null), and `\u{…}`, a Unicode code point written as 1 to 6
hexadecimal digits, such as `\u{1F600}`. Surrogates (`\u{D800}` to
`\u{DFFF}`) and values above `\u{10FFFF}` are not characters.

A backslash that is meant literally, as in a Windows path, is written `\\`.

```trendy,error
var path: text := "C:\data\files";

operator main{} [];
```

```trendy,error
var quote: text := "it\'s";

operator main{} [];
```

Escape the backslash, or remove it where no escape is needed:

```trendy
var path: text := "C:\\data\\files";
var quote: text := "it's";

operator main{} [];
```
