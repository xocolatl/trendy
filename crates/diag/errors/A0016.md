# A0016: operator used as a value

An operator's name is used where a value is expected. Operators are not
values: they can't be passed as arguments or stored. A read-only operator's
call is a value, but an update operator's isn't, so it can't be called in
an expression either. To invoke an update operator, write a `call`
statement.

```trendy,error
operator greet{} [];

operator main{} [
    call debug_value{v: greet};
];
```

A name right before `{}` is the operator when there is one, as the name
after `call` is, so in an expression, `poets{}` is a call of the operator
`poets`. That holds even when a variable or parameter has the name too,
since operators and values have separate namespaces. An update operator
has no value to use in an expression: it is invoked only by a `call`
statement. To project the value of that name on no attributes instead,
parenthesize it, as the fix does:

```trendy,error
var poets := relation { { name: "Ada" } };

operator poets{} [];

operator main{} [
    call debug_table{r: poets{}};
];
```

An update operator gives a result through an `out` parameter, which a
call names the variable for, not as a value, as other languages return
one. So a call of one with one `out` parameter, written as a variable's
new value, is fixed to a `call` statement with the variable its `out`
argument, after declaring it without a value if it is declared there. A
variable of the program can't take it as its initial value at all, which
is computed when compiling, while the call reads input or changes
something when the program runs: its help says to call it in an operator
that runs, such as `main`.

```trendy,error
operator main{} [
    var lines := load_text_file{path: "rivers.txt"};
];
```

```trendy,error
var lines := load_text_file{path: "rivers.txt"};

operator main{} [];
```

Call the operator, with the variable as its `out` argument if it has one,
or parenthesize the value's name:

```trendy
var poets := relation { { name: "Ada" } };
var lines: array text;

operator greet{} [];

operator poets{} [];

operator main{} [
    call greet{};
    call debug_table{r: (poets){}};
    call load_text_file{path: "rivers.txt", out lines: lines};
];
```
