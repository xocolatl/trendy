# A0030: image relation with no tuple at hand

`!!r` is the image relation of the tuple at hand in `r`: the tuples
of `r` that match it on their common attributes, without those attributes.
There is a tuple at hand only where something is computed for one tuple
of a relation at a time: in the values of an `extend` or a `replace`, a
`where`'s condition, and an argument for a `per` parameter. Elsewhere,
`!!r` has no tuple to match.

```trendy,error
var people := relation { { name: "Ada", city: "London" } };
var londoners := !!people;

operator main{} [];
```

Use it in an `extend` or a `replace`, for each tuple of the relation the
groups come from:

```trendy
var people := relation { { name: "Ada", city: "London" } };
var residents := people{city} extend { residents := !!people };

operator main{} [];
```
