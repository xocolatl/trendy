# E0001: unexpected character

The source contains a character that cannot start any token. Identifiers use
ASCII letters, digits and `_`; text literals are enclosed in `"`; and the
only punctuation is `{`, `}`, `[`, `]`, `(`, `)`, `:`, `:=`, `=` and `;`.

```trendy,error
operator main{} [];#
```

Remove the character, or replace it with what you meant:

```trendy

```
