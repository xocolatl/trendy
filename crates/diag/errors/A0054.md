# A0054: an `out` parameter or a variable read before it is assigned, or an `out` parameter not assigned

An `out` parameter takes a variable, as a `var` one does, whose value
before the call is never read: the operator assigns the parameter before
it reads it, and assigns it on every path, whichever way its `if`s and
loops go, so that the variable always has a value the operator gave it.

So reading an `out` parameter before it is assigned on every path to the
read is an error, as is a change to it that reads it, such as `insert`,
or passing it to a `var` parameter:

```trendy,error
operator count_up{out n: integer} [
    var start := n;
    n := start + 1;
];

operator main{} [];
```

And so is an operator that may end without assigning one: an `if`
without `else`, a `while` loop and a `for` loop may not run their
statements, and a transaction that collects its errors may undo them,
so what only they assign isn't assigned on every path. A transaction
without `collecting` assigns what its statements do: if one fails, the
failure goes on, and nothing after the transaction runs.

```trendy,error
operator sign{x: integer, out s: text} [
    if x < 0 then [
        s := "negative";
    ];
];

operator main{} [];
```

Assign it first, on every path, and read it after; or make it `var`, to
read the value of the variable it is passed:

```trendy
operator count_up{var n: integer} [
    var start := n;
    n := start + 1;
];

operator sign{x: integer, out s: text} [
    if x < 0 then [
        s := "negative";
    ] else [
        s := "not negative";
    ];
    call debug_value{v: s};
];

operator main{} [];
```

A local variable whose type has no default, declared without a value, is
the same: it has no value until a statement gives it one, as an assignment
or an `out` argument does, on every path to where it is read.

```trendy,error
type position { { latitude: approximate, longitude: approximate } };

operator locate{out at: position} [
    at := position{latitude: -1.29e0, longitude: 3.682e1};
];

operator report{cities: integer} [
    var at: position;
    if cities > 0 then [
        call locate{out at};
    ];
    call debug_value{v: at};
];

operator main{} [];
```

Give it a value on every path to the read, or where it is declared:

```trendy
type position { { latitude: approximate, longitude: approximate } };

operator locate{out at: position} [
    at := position{latitude: -1.29e0, longitude: 3.682e1};
];

operator main{} [
    var at: position;
    call locate{out at};
    call debug_value{v: at};
];
```
