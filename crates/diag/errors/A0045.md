# A0045: local variable used before its declaration

A local variable is in scope in all of its operator's body, so that its
name means one thing there: it hides any variable of the program with the
same name, before its declaration as well as after. But it has no value
until its declaration gives it one, so a use before then is an error:

```trendy,error
var total := 0;

operator tally{n: integer} [
    total := total + n;
    var total := n * 2;
];

operator main{} [];
```

As in Rust, a variable can't be declared from one of the same name that
it hides: in its own initial value, the name is the local variable's,
which has no value yet:

```trendy,error
var n := 1;

operator next{} [
    var n := n + 1;
    call debug_value{v: n};
];

operator main{} [];
```

Declare a local variable before using it, and give it a name of its own
when it is computed from a variable of the program:

```trendy
var total := 0;
var n := 1;

operator tally{n_added: integer} [
    var doubled := n_added * 2;
    total := total + doubled;
];

operator next{} [
    var following := n + 1;
    call debug_value{v: following};
];

operator main{} [];
```
