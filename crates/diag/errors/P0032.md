# P0032: a loop's spelling

A loop runs its block, in brackets after `loop`, again and again while its
condition, after `while`, is true: `while c loop [ … ];` checks it before
each run, and `loop [ … ] while c;` after, so that its block runs at least
once. `for x in a loop [ … ];` runs it for each element of the array `a`.
Other languages' loops are fixed to these: C's `while (c) { … }`, whose
block has no `loop` before it, and `do { … } while (c);`; Pascal's and
Lua's `while c do … end`, and `repeat … until c`, which runs while `c` is
false: `loop [ … ] while not (c);`; Tutorial D's `WHILE c; … END WHILE;`;
C#'s and PHP's `foreach`; and JavaScript's `for (x of a)`.

A loop ends only once its condition is false, so `break`, `continue` and
Tutorial D's `LEAVE`, which leave early, are reported, without a fix, as
is Python's `while c:`, whose block's end only its indentation shows, and
C's `for (…; …; …)`, which counts with a variable of its own, as a
`while` loop does.

```trendy,error
operator count_down{n: integer} [
    var i := n;
    while (i > 0) {
        i := i - 1;
    };
];

operator main{} [];
```

```trendy,error
operator greet{names: array text} [
    foreach name of names {
        call debug_value{v: name};
    };
];

operator main{} [];
```

```trendy,error
operator count_up{n: integer} [
    var i := 0;
    repeat [
        i := i + 1;
    ] until i = n;
];

operator main{} [];
```

```trendy,error
operator first_over{a: array integer, limit: integer} [
    var i := 1;
    while i <= length{a: a} loop [
        if a[i] > limit then [
            break;
        ];
        i := i + 1;
    ];
];

```

Write the loop's block in brackets after `loop`, and make its condition
false to end it:

```trendy
operator count_down{n: integer} [
    var i := n;
    while i > 0 loop [
        i := i - 1;
    ];
];

operator count_up{n: integer} [
    var i := 0;
    loop [
        i := i + 1;
    ] while not (i = n);
];

operator greet{names: array text} [
    for name in names loop [
        call debug_value{v: name};
    ];
];

operator first_over{a: array integer, limit: integer} [
    var i := 1;
    var found := false;
    while i <= length{a: a} and not found loop [
        if a[i] > limit then [
            found := true;
        ] else [
            i := i + 1;
        ];
    ];
    call debug_value{v: i};
];

operator main{} [];
```
