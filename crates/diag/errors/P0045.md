# P0045: a version with a name of its own

Operators of one name and the same parameters' names are one operator:
the one whose parameters' types are supertypes of the others', its
specification, and versions of it, each for its own parameters' types,
which a call's arguments' values choose (*Type Inheritance and Relational
Theory*, IM Prescription 17). So a version has its specification's name,
and no other: Tutorial D's `VERSION name` is deleted by the fix.

```trendy,error
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

operator sides{f: plane_figure}: integer;
operator sides version sides_e{f: ellipse}: integer [ 0 ];
operator sides version sides_p{f: polygon}: integer [ f.corners ];

operator main{} [];
```
