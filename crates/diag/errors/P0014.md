# P0014: operator from another language

trendy's boolean operators are keywords: `not`, `and`, `or`, `xor` and
`implies`, and so is the remainder of integer division: `mod`. The symbols
other languages use, such as `!`, `&&`, `|`, `^`, `->`, `=>` and `%`, are
not operators in trendy, and the fix replaces each with its keyword. So are
`==` and `!=`: trendy's equality is `=`, and inequality `<>`. (`||` is an
operator: it concatenates text, and so is `!!`, two `!`s together, an
image relation.)

```trendy,error
var ready := true && !false;
var rest := 7 % 2;
var same := rest == 1;

operator main{} [];
```

Write the keywords:

```trendy
var ready := true and not false;
var rest := 7 mod 2;
var same := rest = 1;

operator main{} [];
```
