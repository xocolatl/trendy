# A0043: `per` parameter used as a value

Inside an operator, a `per` parameter is an attribute of its relation's
tuples: the call evaluates its argument once for each of them. So it is
not a value on its own, and is named where the relation's attributes are
in scope: in `r{of}`, `r where …`, `r extend { … }`, `!!r` inside them, or
the argument for another operator's `per r` parameter.

```trendy,error
operator first{r: any relation, of: integer per r}: integer [
    of
];

operator main{} [];
```

Use it as an attribute of the relation's tuples:

```trendy
operator values{r: any relation, of: integer per r}: relation { v: integer } [
    r{of} rename {of as v}
];

operator positive{r: any relation, of: integer per r}: relation { of: integer } [
    (r where of > 0){of}
];

operator main{} [];
```
