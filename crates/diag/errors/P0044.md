# P0044: a type test or a treat written as another language writes it

`x is t` is true if the value of `x` is of the type `t`, or of one of its
subtypes (*Type Inheritance and Relational Theory*, IM Prescription 15),
and in the rest of a condition, `x` is then a `t`:

```trendy
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

operator wide{f: plane_figure}: boolean [
    f is ellipse and f.a > 2e0
];

operator main{} [];
```

Java's and JavaScript's `instanceof`, SQL's `IS OF (t)` and Python's
`isinstance(x, t)` are fixed to it, and SQL's `TREAT(x AS t)` to
`treat x as t`, the value of `x` as one of `t`, which fails unless it is
one (IM Prescription 14):

```trendy,error
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

operator wide{f: plane_figure}: boolean [
    f instanceof ellipse
];

operator round{f: plane_figure}: boolean [
    isinstance(f, ellipse)
];

operator oval{f: plane_figure}: boolean [
    f IS OF (ellipse)
];

operator axis{f: plane_figure}: approximate [
    TREAT(f AS ellipse).a
];

operator main{} [];
```
