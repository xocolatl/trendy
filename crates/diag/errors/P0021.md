# P0021: join written as in SQL

A join is written with one keyword between its operands, and it matches
tuples on the attributes the operands have in common, by name. So SQL's
spellings either mean something trendy writes more simply, or have no
equivalent:

- `natural join` and `inner join` are `join`, and `cross join` is `times`;
  the fix writes the keyword.
- `using (a, b)` names the attributes to match on, which `join` already
  matches; the fix deletes it.
- `on` matches on a condition. Instead, rename attributes so that the ones
  to match have the same name, and the others different names.
- `left join`, `right join` and `full join` fill the missing side with
  nulls, and trendy has no nulls. Keep the tuples without a match apart, as
  a relation of their own.

```trendy,error
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var placed := cities natural join countries;

operator main{} [];
```

```trendy,error
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var placed := cities join countries using (country);

operator main{} [];
```

```trendy,error
var cities := relation { { city: "Kumasi", country_name: "Ghana" } };
var countries := relation { { name: "Ghana", continent: "Africa" } };
var placed := cities join countries on country_name = name;

operator main{} [];
```

```trendy,error
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var placed := cities left outer join countries;

operator main{} [];
```

Write `join`, and rename to match:

```trendy
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var placed := cities join countries;

var named := relation { { city: "Kumasi", country_name: "Ghana" } };
var placed_by_name := named rename {country_name as country} join countries;

operator main{} [];
```
