# A0006: variable needs a type or a value

A variable declaration must give a type, an initial value, or both. Without a
value, the variable starts at its type's default: `0` for `integer` and `""`
for `text`. Without a type, the type is that of the initial value.

```trendy,error
var count;

operator main{} [];
```

A type parameter has no default, since each call of the operator gives it
its type, nor has a tuple with one. A relation or an array with one starts
empty, as any does. So a variable of one needs an initial value where no
statement could decide what it is: a variable of the program's, or a local
variable of a body with no statement that decides what runs next, which could
as well have it where it is declared. In any other body, a statement can assign
it first (see A0054).

```trendy,error
operator twice{v: T}: T types { T: any type } [
    var copy: T;
    v
];

operator main{} [];
```

Nor has a type of the program's own, since no value of it is any more a
start than another, nor a tuple with one:

```trendy,error
type celsius { { degrees: approximate } };

var noon: celsius;

operator main{} [];
```

Give a type, a value, or both:

```trendy
var count: integer;
var total := 0;
var name: text := "trendy";

operator twice{v: T} types { T: any type } [
    var copy: T := v;
    call debug_table{r: relation { { v: copy } }};
];

operator sorted{r: relation { v: T }} types { T: any ordered } [
    var values: array T;
    load values value from r order [asc v];
    call debug_value{v: values};
];

operator main{} [];
```
