# A0006: variable needs a type or a value

A variable declaration must give a type, an initial value, or both. Without a
value, the variable starts at its type's default: `0` for `integer` and `""`
for `text`. Without a type, the type is that of the initial value.

```trendy,error
var count;

operator main{} [];
```

A type with a type parameter in it has no default, since each call of the
operator gives the type parameter its type, so a local variable of one
needs an initial value:

```trendy,error
operator twice{v: T} types { T: any type } [
    var copy: T;
];

operator main{} [];
```

Nor has a type of the program's own, since no value of it is any more a
start than another, nor a tuple with one:

```trendy,error
type celsius { { degrees: approximate } };

var noon: celsius;

operator main{} [];
```

Give a type, a value, or both:

```trendy
var count: integer;
var total := 0;
var name: text := "trendy";

operator twice{v: T} types { T: any type } [
    var copy: T := v;
    call debug_table{r: relation { { v: copy } }};
];

operator main{} [];
```
