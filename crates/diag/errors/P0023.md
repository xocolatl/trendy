# P0023: `delete` without `where`

`delete r where p;` deletes the tuples of the relation variable `r` for
which the condition `p` is true. The condition is required, so that a
`delete` cut short, or written as SQL's `DELETE FROM r`, doesn't delete
every tuple by accident.

```trendy,error
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    delete poets;
];
```

To delete every tuple, assign the empty relation, whose heading comes from
the variable; the fix writes that, which is what Tutorial D's `DELETE R`
means. To delete the tuples of another relation, assign the difference, as
the fix writes, or use `i_delete r s;`, which also checks that each is
there (R0007):

```trendy,error
var poets := relation { { name: "Ada", born: 1815 } };
var gone := relation { { name: "Ada", born: 1815 } };

operator main{} [
    delete poets gone;
];
```

```trendy
var poets := relation { { name: "Ada", born: 1815 } };
var gone := relation { { name: "Ada", born: 1815 } };

operator main{} [
    delete poets where born < 1900;
    poets := relation {};
    poets := poets minus gone;
    i_delete poets gone;
];
```
