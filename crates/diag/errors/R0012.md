# R0012: a file can't be read

`load_text_file` reads the file at its `path` when the program runs, and
the program stops if it can't: if there is no file there, if the program
isn't allowed to read it, or if it is a directory. It writes the path and
the system's reason to stderr, as in `error[R0012]: can't read
"rivers.txt": No such file or directory`, and exits with status 1.

The compiler never opens the file, so this is reported only when the
program runs, and a file missing when compiling is no error. A relative
path is relative to the directory the program runs in, not the one its
source is in:

```trendy
operator main{} [
    var lines := load_text_file{path: "rivers.txt"};
    call debug_table{r: lines};
];
```

Check that the path names a file, from where the program runs, and that
the program's user can read it.
