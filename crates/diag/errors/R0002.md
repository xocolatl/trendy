# R0002: division by zero

`/`, `div` and `mod` have no result when the divisor is zero. For `/`,
that is an error too, never an infinity or a NaN: approximate numbers are
finite.

When the divisor is known while compiling to be zero, the division is
reported there, whatever the dividend is:

```trendy,error
operator half{n: integer} [
    call debug_value{v: n div 0};
];

operator main{} [];
```

```trendy,error
var r := 1e0 / 0e0;

operator main{} [];
```

When the divisor is known only when the program runs, the program stops at
the division instead, writing it, with its operands' values, to stderr, as
in `error[R0002]: division by zero: 7 div 0 has no result`, and exiting
with status 1.

Divide by something other than zero:

```trendy
operator half{n: integer} [
    call debug_value{v: n div 2};
];

operator main{} [];
```
