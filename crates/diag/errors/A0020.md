# A0020: key on a variable that isn't a relation

A key says that no two tuples of a relation have the same values for its
attributes, so only a relation variable can have one. A tuple variable
holds a single tuple, and a scalar variable no tuples at all. The fix
removes the key.

```trendy,error
var capital := tuple { city: "Nairobi", country: "Kenya" } key { city };

operator main{} [];
```

Remove the key, or make the variable a relation if it was meant to hold
several tuples:

```trendy
var capital := tuple { city: "Nairobi", country: "Kenya" };
var capitals := relation { { city: "Nairobi", country: "Kenya" } } key { city };

operator main{} [];
```
