# A0036: a read-only operator that calls itself

A read-only operator can't call itself, directly or through other
read-only operators, and a type's constraint can't select a value of its
type: every selection checks the constraints, so the constraint would
check itself again. trendy has no recursion yet: whether a recursive call
would stop when the compiler computes it, and how deep one can go when the
program runs, are still to be settled. The error names the operators in
the cycle, with a label at each call, whatever their bodies are:

```trendy,error
operator countdown{n: integer}: integer [
    countdown{n: n - 1}
];

operator main{} [];
```

```trendy,error
operator even{n: integer}: boolean [
    odd{n: n - 1}
];

operator odd{n: integer}: boolean [
    even{n: n - 1}
];

operator main{} [];
```

```trendy,error
operator countdown{n: integer}: integer [
    var left := n;
    if left > 0 then [
        left := countdown{n: left - 1};
    ];
    left
];

operator main{} [];
```

A type's constraints are checked whenever a value of it is selected, by
its selector, `replace` or `update`, so a constraint that selects one,
directly or through operators, is a cycle too:

```trendy,error
type fraction {
    { numerator: integer, denominator: integer },
    constraint fraction{numerator: numerator, denominator: denominator} <> fraction{numerator: 0, denominator: 0},
};

operator main{} [];
```

So is a possible representation's own constraint that selects a value in
that representation, which checks it of the components given:

```trendy,error
type tens {
    { n: integer },
    { big: integer, constraint tens{big: big - 10}.n >= 0 }
        to { n := big div 10 }
        from { big := n * 10 },
};

operator main{} [];
```

Compute the value without calling the operator from its own body, and a
constraint from the components alone:

```trendy
operator even{n: integer}: boolean [
    n mod 2 = 0
];

operator odd{n: integer}: boolean [
    not even{n: n}
];

type fraction {
    { numerator: integer, denominator: integer },
    constraint denominator <> 0,
};

type tens {
    { n: integer },
    { big: integer, constraint big >= 10 }
        to { n := big div 10 }
        from { big := n * 10 },
};

operator main{} [];
```
