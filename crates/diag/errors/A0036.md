# A0036: a read-only operator that calls itself

A read-only operator can't call itself, directly or through other
read-only operators. trendy has no conditional yet, so nothing could stop
the calls: its value would never be computed. The error names the
operators in the cycle, with a label at each call.

```trendy,error
operator countdown{n: integer}: integer [
    countdown{n: n - 1}
];

operator main{} [];
```

```trendy,error
operator even{n: integer}: boolean [
    odd{n: n - 1}
];

operator odd{n: integer}: boolean [
    even{n: n - 1}
];

operator main{} [];
```

Compute the value without calling the operator from its own body:

```trendy
operator even{n: integer}: boolean [
    n mod 2 = 0
];

operator odd{n: integer}: boolean [
    not even{n: n}
];

operator main{} [];
```
