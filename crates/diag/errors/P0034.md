# P0034: a definition inside an operator

A heading is declared at the top level, as operators and the program's
variables are: they are definitions of the program, which any operator
can use. An operator's body declares only local variables, with `var`. A
heading declared in a body, as other languages declare a local type, is
moved before the operator.

```trendy,error
operator main{} [
    heading home := { city: text, rooms: integer };
    var homes: relation home;
    call debug_table{r: homes};
];
```

Declare it at the top level:

```trendy
heading home := { city: text, rooms: integer };

operator main{} [
    var homes: relation home;
    call debug_table{r: homes};
];
```
