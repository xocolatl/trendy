# R0008: key violated

No two tuples of a relation variable can have the same values for one of
its keys. A key is a rule about what the variable can hold, so a value that
breaks it is rejected. Either two tuples describe the same thing and one of
them is wrong, or the key itself is wrong.

An initial value is checked when compiling, and the error points at the two
tuples:

```trendy,error
var capitals := relation {
    { country: "Kenya", city: "Nairobi" },
    { country: "Kenya", city: "Mombasa" },
}
key { country };

operator main{} [];
```

An assigned value is checked once it is assigned, or, in an `assign`
block, once all of the block's assignments are. When it is known while
compiling, it is checked then:

```trendy,error
var capitals := relation { { country: "Kenya", city: "Nairobi" } } key { country };

operator main{} [
    insert capitals relation { { country: "Kenya", city: "Mombasa" } };
    capitals := relation {
        { country: "Kenya", city: "Nairobi" },
        { country: "Kenya", city: "Mombasa" },
    };
];
```

When it is known only when the program runs, as the `insert` above, the
program stops at the assignment instead, writing `error[R0008]: two tuples
of a variable have the same values for one of its keys` to stderr and
exiting with status 1.

Correct or remove the tuple, or declare the key that was meant:

```trendy
var capitals := relation {
    { country: "Kenya", city: "Nairobi" },
    { country: "Peru", city: "Lima" },
}
key { country };

var cities := relation {
    { country: "Kenya", city: "Nairobi" },
    { country: "Kenya", city: "Mombasa" },
}
key { city };

operator main{} [];
```

`key {}`, the key with no attributes, allows at most one tuple:

```trendy,error
var settings := relation {
    { language: "fr", region: "SN" },
    { language: "wo", region: "SN" },
}
key {};

operator main{} [];
```
