# A0019: `main` with parameters or a result type

Execution starts in `main`, an update operator: nothing passes it
arguments, and nothing receives a value from it. So `main` has no
parameters and no result type. The fix removes them, and, with a result
type, the value its body ends with.

```trendy,error
operator main{args: text} [];
```

```trendy,error
operator main{}: integer [
    0
];
```

Remove them:

```trendy
operator main{} [];
```
