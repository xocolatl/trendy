# A0019: `main` with parameters or a result type

Execution starts in `main`, an update operator: nothing passes it
arguments, and nothing receives a value from it. So `main` has no
parameters, but the errors it gives, and no result type. The fix removes
them, and, with a result type, the value its body ends with.

```trendy,error
operator main{args: text} [];
```

```trendy,error
operator main{}: integer [
    0
];
```

Remove them:

```trendy
operator main{} [];
```

The errors it gives are its one parameter, `out errors: relation
transaction_collection`, which the program writes when `main` returns,
the warnings, then the failures, exiting with 1 if one failed. The fixes
make `errors` an `out` parameter, and of that type, the type a
transaction collects into:

```trendy,error
operator main{errors: relation transaction_collection} [];
```

```trendy,error
operator main{out errors: relation { error: error }} [
    errors := relation {};
];
```

```trendy
operator main{out errors: relation transaction_collection} [
    var found: relation transaction_collection;
    transaction collecting found [
        warn failure{message: "nothing to do"};
    ];
    errors := found;
];
```
