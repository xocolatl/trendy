# E0006: unterminated text literal

A text literal starts with `"` and must end with `"` on the same line. A
literal can't contain a raw line break: write `\n` instead. A `\"` inside the
literal is an escaped quote, not the end of the literal.

```trendy,error
var t: text := "hello;

operator main{} [];
```

Close the literal:

```trendy
var t: text := "hello";

operator main{} [];
```
