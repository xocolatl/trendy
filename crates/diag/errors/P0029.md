# P0029: a branch without brackets

Each branch of an `if` statement is a block in brackets, even of one
statement: `if c then [ … ] else [ … ];`. So a statement added to a
branch can't end up outside it, as it can in a language where one
statement needs no braces, and an `else` always belongs to the `if` it
follows. A statement without brackets, and Pascal's `begin … end` and
Tutorial D's `BEGIN; … END`, are fixed to brackets; C's `{ … }` is P0003.

```trendy,error
operator report{n: integer} [
    if n = 0 then call debug_value{v: "none"}; else call debug_value{v: n};
];

operator main{} [];
```

```trendy,error
operator report{n: integer} [
    if n = 0 then begin
        call debug_value{v: "none"};
    end else begin
        call debug_value{v: n};
    end;
];

operator main{} [];
```

Write each branch in brackets, and end the `if` with `;`:

```trendy
operator report{n: integer} [
    if n = 0 then [
        call debug_value{v: "none"};
    ] else [
        call debug_value{v: n};
    ];
];

operator main{} [];
```
