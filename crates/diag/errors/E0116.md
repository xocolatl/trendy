# E0116: operator used as a value

An operator's name is used where a value is expected. Operators are not
values: they can't be passed as arguments or stored. To invoke an update
operator, write a `call` statement.

```trendy,error
operator greet{} [];

operator main{} [
    call debug_value{v: greet};
];
```

Call the operator instead:

```trendy
operator greet{} [];

operator main{} [
    call greet{};
];
```
