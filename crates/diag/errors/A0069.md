# A0069: `tclose` of a relation that isn't two attributes of one type

`r tclose`, the transitive closure of `r`, takes a relation of two
attributes of one type, each tuple an arc from one value to another, and
is the relation of the same heading with a tuple for every path: `{ a:
x, b: y }` is in it if `r` has an arc from `x` to `y`, or one from `x`
to some `z` from which the closure reaches `y` (TTM, chapter 6, with
RM Prescription 19).
Which attribute an arc starts at doesn't matter: closing the arcs the
other way round gives the same tuples.

```trendy
var flows := relation {
    { from: "Kagera", to: "Victoria" },
    { from: "Victoria", to: "White Nile" },
    { from: "White Nile", to: "Nile" },
    { from: "Blue Nile", to: "Nile" },
};
var into_the_nile := (flows tclose where to = "Nile"){from};

operator main{} [];
```

A relation of more attributes, or of two of different types, has no
arcs to follow until the program says which attributes are their ends,
by projecting it on two of one type, after converting one with `extend`
if they are of two. The help names the pairs of one type there are:

```trendy,error
var flows := relation {
    { from: "Kagera", to: "Victoria", km: 400 },
    { from: "Victoria", to: "White Nile", km: 130 },
};
var reached := flows tclose;

operator main{} [];
```

```trendy,error
var ranks := relation { { river: "Nile", rank: 1 }, { river: "Amazon", rank: 2 } };
var reached := ranks tclose;

operator main{} [];
```

A cycle is a path from a value to itself, which the closure has a tuple
for: `r tclose where a = b` is the values on a cycle.
