# P0010: keyword in the wrong case

Keywords are case-sensitive, and every keyword is lowercase: `operator`,
`var`, `tuple`, `relation`, `true` and `false`. The capitalized spellings of
other languages, such as Python's `True` or the uppercase `VAR`, `TUPLE`,
`RELATION` and `TRUE` of SQL and Tutorial D, are not keywords in trendy.

```trendy,error
var done: boolean := False;

operator main{} [];
```

```trendy,error
VAR ready := true;

operator main{} [];
```

```trendy,error
var point: TUPLE { x: rational };

operator main{} [];
```

Write the keyword in lowercase:

```trendy
var done: boolean := false;
var ready := true;
var point: tuple { x: rational };

operator main{} [];
```
