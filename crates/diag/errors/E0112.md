# E0112: duplicate tuple

A relation is a set of tuples, so each tuple can appear in a relation value
only once. Since tuples' attributes are unordered, `{ a: 1, b: 2 }` and
`{ b: 2, a: 1 }` are the same tuple. A duplicate is usually a copy-and-paste
mistake, or a typo in what was meant to be a different tuple. The fix
removes it.

```trendy,error
var r := relation { { a: 1, b: 2 }, { b: 2, a: 1 } };

operator main{} [];
```

Remove the duplicate, or change it into the tuple that was meant:

```trendy
var r := relation { { a: 1, b: 2 }, { a: 3, b: 4 } };

operator main{} [];
```
