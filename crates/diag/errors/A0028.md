# A0028: wrong common attributes for the join

The three joins are one operation, which pairs the tuples of two relations
that agree on their common attributes. They differ in what they require of
those attributes, so that an attribute shared, or not, by mistake is
caught:

- `join` needs at least one attribute in common, which it matches on;
- `compose` needs at least one too, and leaves them out of the result;
- `times` needs none in common, and pairs every tuple of one operand with
  every tuple of the other.

For a list, as in `join{r, s, t}`, each operand of `join` must have an
attribute in common with another, so that they all connect, and no two
operands of `times` may share one. `compose[r, s, t]` composes from the
left, so `r` and `s` must have an attribute in common, and so must
`r compose s` and `t`.

Operands with no attributes in common usually mean an attribute is named
differently on each side. When names are close, the error suggests the
rename.

```trendy,error
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { county: "Ghana", continent: "Africa" } };
var placed := cities join countries;

operator main{} [];
```

`!!r` matches `r` with the tuple at hand the same way, so `r` must
have an attribute in common with it too:

```trendy,error
var nations := relation { { country: "Ghana" } };
var towns := relation { { town: "Kumasi", county: "Ghana" } };
var by_nation := nations extend { towns := !!towns };

operator main{} [];
```

```trendy,error
var sizes := relation { { size: "small" }, { size: "large" } };
var colours := relation { { colour: "indigo", size: "small" } };
var variants := sizes times colours;

var nations := relation { { country: "Ghana" } };
var towns := relation { { town: "Kumasi", county: "Ghana" } };
var by_nation := nations extend { towns := !!(towns rename {county as country}) };

operator main{} [];
```

Rename so the attributes to match have the same name, and use `times` only
for operands with nothing in common:

```trendy
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { county: "Ghana", continent: "Africa" } };
var placed := cities join countries rename {county as country};

var sizes := relation { { size: "small" }, { size: "large" } };
var colours := relation { { colour: "indigo" }, { colour: "ochre" } };
var variants := sizes times colours;

var nations := relation { { country: "Ghana" } };
var towns := relation { { town: "Kumasi", county: "Ghana" } };
var by_nation := nations extend { towns := !!(towns rename {county as country}) };

operator main{} [];
```
