# E0101: name defined more than once

Two top-level definitions have the same name. Variables and operators share
one namespace, so every variable and operator in a program needs a unique
name. Types have a namespace of their own, so a variable can have the same
name as a type. The error points at the second definition and notes where the
first one is.

```trendy,error
operator main{} [];

operator main{} [];
```

```trendy,error
var main: integer := 0;

operator main{} [];
```

Delete the duplicate, or rename one of the definitions:

```trendy
var counter: integer := 0;

operator main{} [];
```
