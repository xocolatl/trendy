# R0001: arithmetic overflow

An arithmetic operator whose result is out of its type's range has no
result. It never wraps around, saturates, or becomes an infinity.

- Integers are 64-bit signed, from -9223372036854775808 to
  9223372036854775807. `-9223372036854775808 div -1` overflows, because the
  quotient would be 9223372036854775808, and so does negating the smallest
  integer.
- Approximate numbers are finite, up to about 1.8e308 in magnitude. A result
  beyond that overflows. A result too small to represent is rounded, toward
  zero if need be, as IEEE 754 arithmetic rounds; that is not an error.

A `sum` or a `product` overflows only if its exact result is out of
range: it adds or multiplies the values exactly, then rounds once, so no
order of adding or multiplying them, which a relation's tuples don't have,
can overflow on the way.

When the operands are known while compiling, the overflow is reported
there:

```trendy,error
var big := 9223372036854775807 + 1;

operator main{} [];
```

```trendy,error
var huge := 1e300 * 1e10;

operator main{} [];
```

```trendy,error
var balances := relation { { account: 1, cents: 9223372036854775807 }, { account: 2, cents: 1 } };
var total := sum{r: balances, of: cents};

operator main{} [];
```

When an operand is known only when the program runs, the program stops at
the overflowing operator instead, writing the operation, with its
operands' values, to stderr, as in `error[R0001]: overflow:
9223372036854775807 + 1 is out of its type's range` or `error[R0001]:
overflow: 1e300 * 1e10 is out of its type's range`, and exiting with
status 1, unless a transaction takes its error, an `overflow { operation
}`. The operation written is the one computed, which the compiler may
have simplified to one that fails for the same operands: `n div -1` is
computed as `-n`. A `sum` or a `product` writes `the sum` or `the
product` as its operation.

Keep the values in range, or rearrange the computation so that no
intermediate result leaves it:

```trendy
var big := 9223372036854775807 - 1 + 1;
var huge := 1e300 / 1e10;

operator main{} [];
```
