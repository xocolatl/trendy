# A0025: redundant key

A key is a set of attributes with two properties (*The Third Manifesto*,
chapter 2): no two tuples have the same values for it, and no smaller set
of its attributes has that property too. A key declared twice says nothing
new, and a key that contains another isn't a key: if `{ code }` already
tells the tuples apart, so does `{ code, name }`. The fix removes the
redundant key.

```trendy,error
var languages := relation { { code: "sw", name: "Kiswahili" } } key { code } key { code };

operator main{} [];
```

```trendy,error
var languages := relation { { code: "sw", name: "Kiswahili" } } key { code } key { code, name };

operator main{} [];
```

Keys that share attributes, without one containing the other, are fine:

```trendy
var languages := relation { { code: "sw", name: "Kiswahili" } } key { code };
var flights := relation { { day: 1, gate: "A3", pilot: "Okafor" } }
key { day, gate }
key { day, pilot };

operator main{} [];
```
