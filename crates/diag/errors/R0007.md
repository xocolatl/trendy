# R0007: removing a tuple that isn't there

`r i_minus s` is `r minus s` where every tuple of `s` is in `r`. It states
that what is removed was there, so a tuple of `s` that `r` lacks is an
error rather than being ignored, as `minus` would. Use it where removing
something absent would mean a mistake.

When the relations are known while compiling, a missing tuple is reported
there, naming it:

```trendy,error
var listed := relation { { name: "Ada" }, { name: "Wangari" } };
var left := relation { { name: "Édouard" } };
var staying := listed i_minus left;

operator main{} [];
```

When a relation is known only when the program runs, the program stops
instead, writing `error[R0007]: i_minus or i_delete removes a tuple that
isn't there` to stderr and exiting with status 1. So does `i_delete r s;`,
which is `r := r i_minus s;`: it deletes tuples that must be there.

If removing what isn't there is fine, write `minus`; otherwise, remove
only what is there:

```trendy
var listed := relation { { name: "Ada" }, { name: "Wangari" } };
var left := relation { { name: "Édouard" } };
var staying := listed minus left;
var checked := listed i_minus (left intersect listed);

operator main{} [];
```
