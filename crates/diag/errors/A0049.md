# A0049: cyclic headings and types

A heading's attributes, and a type's components, can be of the types of
other headings and types, declared in any order, but not of their own,
directly or through others: the type would contain itself. *The Third Manifesto* leaves open whether a
heading can be defined in terms of itself, and, by its Principle of
Cautious Design, assumes it can't (chapter 6, RM Prescription 6); trendy
doesn't allow it. The error lists the headings in the cycle, with a label
at each reference.

```trendy,error
heading part := { name: text, parts: relation part };

operator main{} [];
```

```trendy,error
heading person := { name: text, employer: tuple company };
heading company := { name: text, staff: relation person };

operator main{} [];
```

```trendy,error
type route { { start: text, rest: route } };

operator main{} [];
```

A hierarchy is a relation of pairs instead, each part with one it
contains, as TTM's relvar `MM` is in its part explosion (chapter 6):

```trendy
heading part := { name: text };
heading assembly := { major: text, minor: text };

operator main{} [];
```
