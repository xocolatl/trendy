# R0019: a value treated as one of a type it isn't of

`treat x as t` is the value of `x`, as a value of `t`, a subtype of its
type, which it fails unless it is one of (*Type Inheritance and Relational
Theory*, IM Prescription 14): it says that a value of a union type is one
of a particular subtype, as a test can't when the value isn't the one
tested. When the value is known while compiling, a treat it fails is
reported there; otherwise the program stops when it is made, writing the
value:

```trendy,error
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

var figure: plane_figure := polygon{corners: 4};
var lake := treat figure as ellipse;

operator main{} [];
```

Test the value where it may be of another type, and in the rest of the
condition it is a value of the type tested, with no treat:

```trendy
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

var figure: plane_figure := polygon{corners: 4};
var width := if figure is ellipse then 2e0 * figure.a else 0e0;

operator main{} [];
```
