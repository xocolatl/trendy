# E0014: operator from another language

trendy's boolean operators are keywords: `not`, `and`, `or`, `xor` and
`implies`. The symbols other languages use, such as `!`, `&&`, `||`, `^`,
`->` and `=>`, are not operators in trendy, and the fix replaces each with its
keyword.

```trendy,error
var ready := true && !false;

operator main{} [];
```

Write the keywords:

```trendy
var ready := true and not false;

operator main{} [];
```
