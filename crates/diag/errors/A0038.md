# A0038: type parameter no call can give a type

Each call of an operator gives its type parameters types from its
arguments: a type parameter is the type of an argument, or part of it.
So each one must be in some parameter's type. One that is in none, even if
the result type or the body uses it, would have no type, and one used
nowhere is removed.

```trendy,error
operator empty{n: integer}: relation { v: T }
    types { T: any type }
[
    relation {}
];

operator main{} [];
```

```trendy,error
operator show{v: any type}
    types { T: any type }
[
    call debug_value{v: v};
];

operator main{} [];
```

Write the type parameter as a parameter's type, or use a specific type:

```trendy
operator empty{of: T}: relation { v: T }
    types { T: any type }
[
    relation {}
];

operator show{v: any type} [
    call debug_value{v: v};
];

operator main{} [];
```
