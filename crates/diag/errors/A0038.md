# A0038: a call whose value is known only when running

For now, a read-only operator is called only when compiling: in an initial
value, or in a body with arguments known then, when it reads no variable.
A call whose arguments, or the variables its operator reads, are known only
when the program runs can't be made yet. The error points at the statement
with the call.

```trendy,error
var rate := 3;

operator scaled{x: integer}: integer [
    return x * rate;
];

operator main{} [
    call debug_value{v: scaled{x: 2}};
];
```

Call it where its value is known when compiling, such as in an initial
value:

```trendy
var rate := 3;
var six := scaled{x: 2};

operator scaled{x: integer}: integer [
    return x * rate;
];

operator main{} [
    call debug_value{v: six};
];
```
