# A0084: an early exit with nowhere to go, or nothing to skip

`leave;` leaves the innermost loop it is in, and `iterate;` goes on to that
loop's next run, past the rest of its block, the loop's condition checked
first, as after each run. Each is of a loop of the body, or the value block,
it is in: a value block's statements compute its value, and a loop around the
block is no loop of theirs. So one in no loop is an error:

```trendy,error
operator first_negative{a: array integer}: integer [
    var found := 0;
    for n in a loop [
        if n < 0 then [
            found := n;
        ];
    ];
    leave;
    found
];

operator main{} [];
```

An exit that skips nothing changes nothing: `iterate;` at the end of its
loop's block, where the next run comes anyway, and `return;` at the end of
an update operator's body, which leaves it anyway. The fix deletes it:

```trendy,error
operator count_down{n: integer} [
    var i := n;
    while i > 0 loop [
        i := i - 1;
        iterate;
    ];
];

operator main{} [];
```

```trendy,error
operator greet{name: text} [
    call debug_value{v: "Habari, " || name};
    return;
];

operator main{} [];
```

```trendy
operator first_negative{a: array integer}: integer [
    for n in a loop [
        if n < 0 then [
            return n;
        ];
    ];
    0
];

operator count_down{n: integer} [
    var i := n;
    while i > 0 loop [
        i := i - 1;
    ];
];

operator main{} [];
```
