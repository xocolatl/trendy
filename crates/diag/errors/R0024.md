# R0024: arguments that break a constraint of the operator called

A constraint in an operator's braces says which arguments a call of it can
have, as a type's constraint says which components a value of it can have
(*The Third Manifesto*, RM Prescription 23). Each call checks them first. One
that is false of arguments known when compiling is an error then, whether or
not the call's other arguments are known:

```trendy,error
operator main{} [
    var last := 10;
    call debug_table{r: series{from: 1, to: last, step: 0}};
];
```

and otherwise the program stops where the call is, writing the call with the
arguments the constraint reads, as in ``error[R0024]: series{step: 0} can't be
called: it breaks the constraint `step <> 0` ``, unless a transaction takes its
error, a `broken_call_constraint { called, constraint }`.

Call it with arguments that satisfy the constraint, or, where they come from
data, test them first:

```trendy
operator main{} [
    var step := 2;
    if step <> 0 then [
        call debug_table{r: series{from: 1, to: 5, step: step}};
    ];
];
```
