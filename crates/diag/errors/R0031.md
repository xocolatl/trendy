# R0031: standard input has ended

`read{out line}`, of `trendy.streams`, reads the next line of standard input,
and the program stops if there is none: if standard input was a file or a
pipe that has nothing left, or the person at a terminal ended it, as Ctrl-D
does. It writes how many lines were read, as in `error[R0031]: standard
input has ended, after 3 lines`, and exits with status 1.

A program that asks for a line it needs, as an answer to a prompt, can stop
there: the input it was given has none. One that reads until the end reads
the rest at once, with `read{out lines}`, which gives none if there is none,
or names `out errors`, which then holds the `end_of_input { lines }`:

```trendy
uses { trendy.streams };

operator main{} [
    call write{text: "Name? "};
    var name: text;
    var errors: relation { error: error };
    call read{out line: name, out errors};
    if is_empty{r: errors} then [
        call write{line: "Habari, " || name};
    ] else [
        call write{line: "no name given"};
    ];
    var rest: array text;
    call read{out lines: rest};
    call write{line: to_text{from: length{a: rest}} || " more lines"};
];
```
