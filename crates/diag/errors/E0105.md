# E0105: integer literal out of range

Integers are 64-bit signed, so the largest integer literal is
`9223372036854775807`. There are no negative literals yet, because the
language has no unary minus.

```trendy,error
var big: integer := 9223372036854775808;

operator main{} [];
```

Use a value in range:

```trendy
var big: integer := 9223372036854775807;

operator main{} [];
```
