# P0046: a key inside a heading

A key is a rule of a relation variable, written after its type or its
value, or of a type's relation-valued component, written after the
component's type. It isn't part of a relation type: the values of
`relation { v_no: integer, vertex: point }` are all the relations of that
heading, so an attribute of a heading, or a parameter, can't have a key.

```trendy,error
var shapes: relation {
    name: text,
    vertices: relation { v_no: integer, x: approximate, y: approximate } key { v_no },
};

operator main{} [];
```

To key relations of a heading wherever they are, make them a component of
a type of the program's own, whose values are only those the keys allow:

```trendy
type outline {
    { vertices: relation { v_no: integer, x: approximate, y: approximate } key { v_no } },
};

var shapes: relation { name: text, outline: outline };

operator main{} [];
```

If they are facts in their own right, keep them in a relation variable of
their own, with its keys:

```trendy
var vertices: relation { shape: text, v_no: integer, x: approximate, y: approximate }
    key { shape, v_no };

operator main{} [];
```
