# E0004: expected a definition

Something at the top level of the file is not an operator definition. Every
top-level item is an operator definition, and each one starts with the
keyword `operator`. Keywords from other languages, such as `fn`, `function`,
`def` or `void`, are not used.

```trendy,error
fn main{} [];
```

```trendy,error
void main() {}
```

Start the definition with `operator`:

```trendy
operator main{} [];
```
