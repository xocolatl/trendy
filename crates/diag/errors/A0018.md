# A0018: unnamed argument

A call's arguments are a tuple of the operator's parameters, so each argument
is written `name: value`, in any order. When one argument has no name and
one parameter has no argument, the argument can only be for it, and the
fix adds its name; otherwise nothing says which argument is for which.

```trendy,error
operator greeting{name: text, title: text}: text [ title || " " || name ];

operator main{} [
    call debug_value{42};
    call debug_value{v: greeting{name: "Lovelace", "Countess"}};
];
```

Name the arguments:

```trendy
operator greeting{name: text, title: text}: text [ title || " " || name ];

operator main{} [
    call debug_value{v: 42};
    call debug_value{v: greeting{name: "Lovelace", title: "Countess"}};
];
```

Among operators of one name, which the arguments' names choose, an
argument without a name counts as one for a parameter without one: with
`area{width: integer, height: integer}` and `area{side: integer}`,
`area{3, 4}` is checked against the first, and `area{3}` against the
second.
