# A0018: unnamed argument

A call's arguments are a tuple of the operator's parameters, so each argument
is written `name: value`, in any order. When the operator has exactly one
parameter, the fix adds its name.

```trendy,error
operator main{} [
    call debug_value{42};
];
```

Name the argument:

```trendy
operator main{} [
    call debug_value{v: 42};
];
```
