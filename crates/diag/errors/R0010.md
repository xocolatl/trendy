# R0010: `min` or `max` of no tuples

`min{r: r, of: x}` is the least value of `x` for a tuple of `r`, and
`max{r: r, of: x}` the greatest, by `<`. With no tuples, no value is the
least or the greatest, so both fail. `count`, `some` and `every` don't:
of no tuples, they are 0, false and true.

When the relation is known while compiling, it is reported there:

```trendy,error
var readings := relation { station: text, celsius: integer } {};
var low := min{r: readings, of: celsius};

operator main{} [];
```

When it is known only when the program runs, the program stops instead,
writing `error[R0010]: the relation has no tuples, so it has no min`, or
`max`, to stderr and exiting with status 1.

The image relation of a group, `!!r`, has no tuples when no tuple of `r`
matches the group. Here no reading is from Lima yet:

```trendy,error
var stations := relation { { station: "Nairobi" }, { station: "Ulaanbaatar" }, { station: "Lima" } };
var readings := relation {
    { station: "Nairobi", hour: 6, celsius: 14 },
    { station: "Nairobi", hour: 14, celsius: 25 },
    { station: "Ulaanbaatar", hour: 6, celsius: -21 },
};
var lows := stations extend { low := min{r: !!readings, of: celsius} };

operator main{} [];
```

Extend only the groups that have tuples, which `matching` keeps:

```trendy
var stations := relation { { station: "Nairobi" }, { station: "Ulaanbaatar" }, { station: "Lima" } };
var readings := relation {
    { station: "Nairobi", hour: 6, celsius: 14 },
    { station: "Nairobi", hour: 14, celsius: 25 },
    { station: "Ulaanbaatar", hour: 6, celsius: -21 },
};
var lows := (stations matching readings) extend { low := min{r: !!readings, of: celsius} };

operator main{} [];
```
