# P0041: an order inside the components' braces

A type's order, `order [asc …]`, goes in the type's braces, with its
possible representations and its constraints, not in a representation's
own: it is the type's, whichever representation's components it names,
and says how all of its values compare. A representation's braces hold
its components, and constraints of its own after them, which say which of
its components represent a value. The fix moves the order after the
components' braces:

```trendy,error
type day { { year: integer, month: integer, order [asc year, asc month] } };

operator main{} [];
```

Put the order in the type's braces:

```trendy
type day {
    { year: integer, month: integer },
    order [asc year, asc month],
};

operator main{} [];
```
