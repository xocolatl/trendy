# A0068: an implementation's declaration isn't the interface's

A unit's interface declares an operator by its heading alone, and its
implementation repeats the whole heading with the body: the parameters,
with their modes and types, and the result type, as the interface
declares them. Its name and its parameters' names say which operator it
is, as for any operator:

```trendy
interface

operator deepest{depths: relation { m: integer }}: integer;

implementation

operator deepest{depths: relation { m: integer }}: integer [
    max{r: depths, of: m}
];

operator main{} [];
```

One whose heading differs from the interface's is given the interface's,
so that what other units call is what the implementation defines:

```trendy,error
interface

operator deepest{depths: relation { m: integer }}: integer;

implementation

operator deepest{depths: relation { m: integer }}: approximate [
    to_approximate{from: max{r: depths, of: m}}
];

operator main{} [];
```

A type the interface declares with several possible representations is
declared again in the implementation, with their conversions, and that
declaration repeats the components of each representation it gives them,
as the interface writes them, so that each conversion reads beside what
it converts. One the interface doesn't declare, and components of other
types than the interface's, are errors, the last fixed to the interface's,
whose types the conversions are checked with:

```trendy,error
interface

type duration {
    { seconds: integer },
    { hours: integer, minutes: integer },
};

implementation

type duration {
    { hours: integer, minutes: text }
        to { seconds := hours * 3600 + minutes * 60 }
        from { hours := seconds div 3600, minutes := seconds mod 3600 div 60 },
};

operator main{} [];
```

```trendy,error
interface

type duration {
    { seconds: integer },
    { hours: integer, minutes: integer },
};

implementation

type duration {
    { days: integer }
        to { seconds := days * 86400 }
        from { days := seconds div 86400 },
};

operator main{} [];
```

Repeat the components as the interface writes them. The one its values
are stored as, which has no conversions to give, needn't be repeated:

```trendy
interface

type duration {
    { seconds: integer },
    { hours: integer, minutes: integer },
};

implementation

type duration {
    { hours: integer, minutes: integer }
        to { seconds := hours * 3600 + minutes * 60 }
        from { hours := seconds div 3600, minutes := seconds mod 3600 div 60 },
};

operator main{} [];
```
