# A0068: an operator's heading in the implementation isn't the interface's

A unit's interface declares an operator by its heading alone, and its
implementation repeats the whole heading with the body: the parameters,
with their modes and types, and the result type, as the interface
declares them. Its name and its parameters' names say which operator it
is, as for any operator:

```trendy
interface

operator deepest{depths: relation { m: integer }}: integer;

implementation

operator deepest{depths: relation { m: integer }}: integer [
    max{r: depths, of: m}
];

operator main{} [];
```

One whose heading differs from the interface's is given the interface's,
so that what other units call is what the implementation defines:

```trendy,error
interface

operator deepest{depths: relation { m: integer }}: integer;

implementation

operator deepest{depths: relation { m: integer }}: approximate [
    to_approximate{from: max{r: depths, of: m}}
];

operator main{} [];
```
