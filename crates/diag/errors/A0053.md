# A0053: a variable passed to a `var` parameter that is reached another way too

A `var` parameter's value is its variable's when the operator ends. So
one variable can't be two `var` parameters of one call, whose values
could differ:

```trendy,error
var count := 1;

operator add{var a: integer, var b: integer} [
    a := a + 1;
    b := b + 2;
];

operator main{} [
    call add{var a: count, var b: count};
];
```

Nor can the operator use a variable of the program's that it is passed
as a `var` parameter by its own name too, reading or assigning it, in its
body or in an operator it calls: what the name gives would depend on
whether the parameter is a copy of the variable or the variable itself.

```trendy,error
var count := 1;

operator double{var n: integer} [
    n := count * 2;
];

operator main{} [
    call double{var n: count};
];
```

Pass a different variable to each `var` parameter, and have the operator
use its parameter for what it is passed:

```trendy
var count := 1;

operator double{var n: integer} [
    n := n * 2;
];

operator main{} [
    call double{var n: count};
];
```
