# R0028: an argument that isn't UTF-8 text

`trendy.process`'s `arguments` are the arguments the program is started
with, an `array text`. On most systems an argument is any bytes, but text
is UTF-8, so an argument that isn't can't be one of them. The program
stops before `main` runs, saying which, from 1, so that nothing acts on
what it wasn't given, as dropping it or changing its bytes would. Only a
program that reads or assigns `arguments` is given them.

```trendy
uses { trendy.process };

operator main{} [
    call debug_value{v: arguments};
];
```

Started as `./program café`, with `é` written as Latin-1's one byte rather than
UTF-8's two, it writes `error[R0028]: argument 1 isn't UTF-8 text` to stderr, and
exits with status 1. Give the program UTF-8 text: most terminals and shells write
it already, and `iconv` converts what doesn't.
