# E0103: unknown type

The name after `:` in a variable declaration is not a type. The built-in types
are `integer`, a 64-bit signed integer; `rational`, a 64-bit floating-point
number; and `text`, a UTF-8 string. Names are case-sensitive, and the type
names of other languages, such as `int`, `double` or `string`, are not used.

```trendy,error
var i: int := 0;

operator main{} [];
```

```trendy,error
var t: String := "hello";

operator main{} [];
```

Use a built-in type:

```trendy
var i: integer := 0;
var t: text := "hello";

operator main{} [];
```
