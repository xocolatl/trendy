# A0048: an attribute assigned on its own

A tuple's attributes are changed by `update`: `update t { a := x };` is
shorthand for `t := t replace { a := x };`, which gives the whole variable
a new value. Other languages assign an object's field, as in `t.name = x`,
but an attribute is no variable: TTM notes that attribute extractors could
serve as pseudovariables, targets of an assignment, but Tutorial D's don't
(chapter 3), and neither do trendy's. An array's element is one, so
`a[i] := x` assigns `a`.

The fix writes the assignment as an `update` of the variable, or, for an
attribute of an array's element, as an assignment of the element with the
attribute replaced. Inside the braces, the tuple's attributes are in
scope, so there is no fix when the value names one of them, which would
then mean the attribute.

```trendy,error
var address := tuple { city: "Nairobi", postal_code: "00100" };

operator main{} [
    address.city := "Mombasa";
];
```

```trendy,error
var people := array [{ name: "Wangari", born: 1940 }];

operator main{} [
    people[1].name := "Wangari Maathai";
];
```

Change the attribute with `update`, or give the element a new value:

```trendy
var address := tuple { city: "Nairobi", postal_code: "00100" };
var people := array [{ name: "Wangari", born: 1940 }];

operator main{} [
    update address { city := "Mombasa" };
    people[1] := people[1] replace { name := "Wangari Maathai" };
];
```
