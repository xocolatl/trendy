# A0048: an attribute or a component assigned on its own

A tuple's attributes are changed by `update`: `update t { a := x };` is
shorthand for `t := t replace { a := x };`, which gives the whole variable
a new value. Other languages assign an object's field, as in `t.name = x`,
but an attribute is no variable: TTM notes that attribute extractors could
serve as pseudovariables, targets of an assignment, but Tutorial D's don't
(chapter 3), and neither do trendy's. An array's element is one, so
`a[i] := x` assigns `a`.

The components of a value of a type of the program's own are changed the
same way: `update p { latitude := x };` is shorthand for
`p := p replace { latitude := x };`, the value with that component changed
and the others as they were, as Tutorial D's `UPDATE` of a scalar
variable is (TTM chapter 5). Tutorial D also has THE_ pseudovariables,
`THE_X ( P ) := X`, but trendy's `p.latitude`, like an attribute's
extraction, is no variable to assign.

The fix writes the assignment as an `update` of the variable, or, for an
attribute or a component of an array's element, as an assignment of the
element with it replaced. A tuple or a value inside is changed with
`replace`. Inside the braces, the tuple's attributes, or the value's
components, are in scope, so there is no fix when the value names one of
them, which would then mean the attribute or the component.

```trendy,error
var address := tuple { city: "Nairobi", postal_code: "00100" };

operator main{} [
    address.city := "Mombasa";
];
```

```trendy,error
var people := array [{ name: "Wangari", born: 1940 }];

operator main{} [
    people[1].name := "Wangari Maathai";
];
```

```trendy,error
type position { { latitude: approximate, longitude: approximate } };

var stop := tuple { name: "Nairobi", at: position{latitude: -1.29e0, longitude: 36.82e0} };

operator main{} [
    stop.at.latitude := -1.28e0;
];
```

Change the attribute or the component with `update`, or give the element
a new value:

```trendy
type position { { latitude: approximate, longitude: approximate } };

var address := tuple { city: "Nairobi", postal_code: "00100" };
var people := array [{ name: "Wangari", born: 1940 }];
var stop := tuple { name: "Nairobi", at: position{latitude: -1.29e0, longitude: 36.82e0} };

operator main{} [
    update address { city := "Mombasa" };
    people[1] := people[1] replace { name := "Wangari Maathai" };
    update stop { at := at replace { latitude := -1.28e0 } };
];
```
