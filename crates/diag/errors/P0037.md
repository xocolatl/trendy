# P0037: a named operand

The operands of a list, such as `and{a, b, c}`, `join{r, s, t}` or
`compose[r, s]`, are values, written without names, as the operands of
`a and b` are. A call's arguments are named, `count{r: r}`, since they are
a tuple of the operator's parameters, each a different thing; a list's
operands are any number of the same thing, so none has a name. The fix
removes the name.

```trendy,error
var warm := true;
var dry := false;
var fire_risk := and{warmth: warm, drought: dry};

operator main{} [];
```

Write the values:

```trendy
var warm := true;
var dry := false;
var fire_risk := and{warm, dry};

operator main{} [];
```
