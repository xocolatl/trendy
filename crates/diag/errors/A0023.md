# A0023: an empty list that does nothing

`remove` drops the attributes it names from a tuple or relation, `rename`
renames them, `extend` adds new ones, `replace` gives existing ones, or
the components of a value of a type of the program's own, new values,
`group` and `wrap` gather them into new relation-valued and
tuple-valued ones, and `ungroup` and `unwrap` replace those with their
attributes, so each must name at least one. With none, the result would be
the operand itself, which is almost certainly not what was meant. The fix
drops the empty operator, such as `remove {}`.

```trendy,error
var ada := tuple { name: "Ada", born: 1815 };
var same := ada remove {};

operator main{} [];
```

So it is with statements: an `update` with no attributes, `update r {};`,
or no components, of a value of a type of the program's own, and an
`assign` block with no assignments, `assign {};`, would change
nothing, and the fix deletes them.

```trendy,error
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    update poets {};
    assign {};
];
```

Name the attributes to drop, or, to keep none of them, project on none,
`ada{}`, and name the attributes to update:

```trendy
var ada := tuple { name: "Ada", born: 1815 };
var name := ada remove {born};
var nothing := ada{};
var poets := relation { { name: "Ada", born: 1815 } };

operator main{} [
    update poets { born := born + 1 };
];
```
