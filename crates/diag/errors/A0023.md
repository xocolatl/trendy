# A0023: an operator with an empty list does nothing

`remove` drops the attributes it names from a tuple or relation, `rename`
renames them, `extend` adds new ones, `replace` gives existing ones new
values, `group` gathers them into new relation-valued ones, and `ungroup`
replaces relation-valued ones with their attributes, so each must name at
least one. With none, the result would be the operand itself, which is
almost certainly not what was meant. The fix drops the `remove {}`,
`rename {}`, `extend {}`, `replace {}`, `group {}` or `ungroup {}`.

```trendy,error
var ada := tuple { name: "Ada", born: 1815 };
var same := ada remove {};

operator main{} [];
```

Name the attributes to drop, or, to keep none of them, project on none,
`ada{}`:

```trendy
var ada := tuple { name: "Ada", born: 1815 };
var name := ada remove {born};
var nothing := ada{};

operator main{} [];
```
