# P0057: a `uses` written as another language writes one

A section names the units it uses with `uses`, first in it: each unit by
its path from the directory of `main`'s file, its directories and its
file's stem between `.`s, as `lakes/depths.trendy` is `lakes.depths`, and,
after `as`, by one word the using unit gives it. The units are in braces,
as they can be in any order, and every name a unit's interface declares
comes with it. For the unit `lakes/depths.trendy`:

```trendy,unit lakes.depths
interface

heading lake := { name: text, depth: integer };

operator deepest{lakes: relation lake}: relation lake;

implementation

operator deepest{lakes: relation lake}: relation lake [
    lakes where depth = max{r: lakes, of: depth}
];
```

a program uses it so:

```trendy
uses { lakes.depths as depths };

operator main{} [];
```

Delphi's `uses` without braces is fixed with them, and a `uses` of no
unit is removed:

```trendy,error
uses lakes.depths;

operator main{} [];
```

A unit's name is words between `.`s, so Rust's and C++'s `::`, a path's
`/`, a path in quotes, and Java's `.*` after it, are fixed to its name:

```trendy,error
uses { lakes::depths, "recipes/soups.trendy", birds.* };

operator main{} [];
```

Other languages' imports are fixed to the `uses` they mean: Python's
`import` and `from … import`, Java's and Haskell's `import`, Go's and
JavaScript's paths in quotes, Rust's `use` of a module's names, C#'s
`using`, C++'s `using namespace`, Ruby's and Lua's `require`, Ada's
`with`, OCaml's `open`, and C's `#include`:

```trendy,error
from lakes.depths import deepest

operator main{} [];
```

```trendy,error
import { deepest } from "./lakes/depths.js";

operator main{} [];
```

```trendy,error
#include "lakes/depths.h"

operator main{} [];
```

Rust's `use lakes::depths::deepest;` imports `deepest` from the module
`lakes::depths`, or the module `lakes::depths::deepest`, which only the
program knows, so it is reported with help, naming both:

```trendy,error
use lakes::depths::deepest;

operator main{} [];
```
