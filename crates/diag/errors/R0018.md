# R0018: an operation with no result

Approximate numbers are finite, with no NaN, nor any other value standing
for a result that isn't a number, so an operation with no result fails
instead of giving one: the square root of a negative number, which no
approximate number's square is.

When the operand is known while compiling, that is reported there:

```trendy,error
var side := sqrt{of: -4e0};

operator main{} [];
```

When it is known only when the program runs, the program stops instead,
writing the operand to stderr, as in `error[R0018]: -4e0 has no square
root`, and exiting with status 1, unless a transaction takes its error, a
`no_square_root { of }`.

Take the square root of a number that is zero or more, such as a sum of
squares:

```trendy
var side := sqrt{of: 3e0 * 3e0 + 4e0 * 4e0};

operator main{} [];
```
