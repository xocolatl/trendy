# P0060: not one character in single quotes

A character literal is one character between single quotes, as a reader sees one:
`'a'`, `'é'`, `'🇸🇪'`, or `'👨‍👩‍👧‍👦'`, whatever number of code points it is made of. Text is
written between double quotes, though SQL, Tutorial D, Python and JavaScript all write
it between single quotes too:

```trendy,error
var city := 'Nairobi';

operator main{} [];
```

```trendy
var city := "Nairobi";
var initial := 'N';

operator main{} [];
```

No character is empty, so `''` is the empty text, `""`, and a single quote is written
`'\''`:

```trendy,error
var nothing := '';

operator main{} [];
```

```trendy,error
var quote := ''';

operator main{} [];
```

```trendy
var nothing := "";
var quote := '\'';

operator main{} [];
```

A character literal must end on the line it starts, as a text literal must. What one
character is comes from the rules of Unicode's UAX #29, at the version of Unicode the
language pins (see the reference's Characters section), so `'\r\n'` is one, and two
flags in one literal aren't.
