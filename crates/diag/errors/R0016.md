# R0016: a column that isn't one of a CSV file's

`load_csv` reads a CSV file's records into an array of tuples, each
attribute the field in the column `columns` gives it. A file's columns
have an order and no names, so `columns` gives each attribute the
position of its column, counting from 1, as an array's positions do,
and each its own: two attributes can't be read from one column.

A position below 1, or that two attributes have, is no attribute's
column. When the positions are known when compiling, as a tuple
selector's are, that is an error then:

```trendy,error
operator main{} [
    var rows: array tuple { city: text, people: integer };
    call load_csv{
        path: "cities.csv",
        header: true,
        columns: tuple { city: 1, people: 1 },
        out rows: rows,
    };
];
```

Otherwise the program stops when it runs, writing the attribute and the
position to stderr, and exits with status 1, as it does for a position
past the file's last column, which only the file can tell, as in
`error[R0016]: `people` is read from column 6, but "cities.csv" has 5
columns`.

Give each attribute the position of its column:

```trendy
operator main{} [
    var rows: array tuple { city: text, people: integer };
    call load_csv{
        path: "cities.csv",
        header: true,
        columns: tuple { city: 1, people: 3 },
        out rows: rows,
    };
];
```
