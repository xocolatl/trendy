# R0016: a CSV file's header doesn't name each attribute once

`load_csv` reads a CSV file's records into an array of tuples. The file's
first record, its header, names its columns, and each attribute of the
tuples is the field in the column of its name, exactly, so `City` and
` city` aren't `city`. Columns the tuples don't name are skipped.

When the program runs, it stops if the header names an attribute in no
column, writing the header's names, as in `error[R0016]: "cities.csv"
has no column "people", for the attribute of that name; its header
names "city", "population"`, or in two, or if the file has no header,
and exits with status 1.

The compiler never opens the file, so this is reported only when the
program runs. Name the attributes as the header names the columns:

```trendy
operator main{} [
    var rows: array tuple { city: text, population: integer };
    call load_csv{path: "cities.csv", out rows: rows};
    call debug_value{v: rows};
];
```
