# E0117: not an operator

`call` names something that isn't an operator, such as a variable or a
parameter. `call` invokes an update operator: one of the program's own
operators, or a built-in such as `debug_value`.

```trendy,error
var greet := "hello";

operator main{} [
    call greet{};
];
```

Call an operator, passing the value as an argument:

```trendy
var greet := "hello";

operator main{} [
    call debug_value{v: greet};
];
```
