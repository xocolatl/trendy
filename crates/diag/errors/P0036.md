# P0036: a compound assignment

C, Python, JavaScript and Rust change a variable from its own value with
an operator and `=`, as in `total += price`, and C and JavaScript add or
take away 1 with `++` and `--`. trendy has neither: an assignment gives a
variable its new value in full, with `:=`, as Tutorial D's does, which has
no such shorthand either (TTM, Appendix I). The fix writes the assignment
it means, with the value in parentheses where the operator would
otherwise take only part of it: `x *= a + b` is `x := x * (a + b)`. `%`
is `mod`.

```trendy,error
var total := 0;

operator add{price: integer} [
    total += price;
];

operator main{} [];
```

```trendy,error
var visits := 0;

operator visit{} [
    visits++;
];

operator main{} [];
```

Assign the new value:

```trendy
var total := 0;
var visits := 0;

operator add{price: integer} [
    total := total + price;
];

operator visit{} [
    visits := visits + 1;
];

operator main{} [];
```
