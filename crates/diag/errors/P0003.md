# P0003: wrong delimiters

A parameter list or body is enclosed in the wrong kind of brackets. In
trendy, parameter lists use braces `{}` and bodies use square brackets `[]`.
This differs from C-family languages, where parameters use `()` and bodies
use `{}`.

```trendy,error
operator main() [];
```

```trendy,error
operator main{} {};
```

The suggestion replaces both the opening and the closing delimiter:

```trendy
operator main{} [];
```
