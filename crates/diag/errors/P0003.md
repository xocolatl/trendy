# P0003: wrong delimiters

Something is enclosed in the wrong kind of brackets. In trendy, braces `{}`
enclose what can be in any order, and square brackets `[]` what can't:

- parameters and arguments, headings, tuples and relations, lists of
  attribute names, and the operands of `join{…}` and `times{…}` are in
  braces;
- a body's statements, and the operands of `compose[…]`, which composes
  from the left, are in brackets.

The list of an `extend`, a `replace`, a `group` or a `wrap` is in braces,
since its items apply all at once. Brackets would ask for them in order,
which is what a chain of the operator does, so the fix is that chain, not
braces, which would change the meaning: `r group [x := {a}, y := {b}]` is
fixed to `r group { x := {a} } group { y := {b} }`. A list of attribute
names is in braces even with one name, so a bare `ungroup g` is fixed to
`ungroup {g}`, and `unwrap w` to `unwrap {w}`.

Parentheses only group an expression. C-family languages enclose parameters
in `()` and bodies in `{}`, and the error recognizes that habit.

```trendy,error
operator main() [];
```

```trendy,error
operator main{} {};
```

```trendy,error
var a := relation { { x: 1 } };
var b := join[a, a];

operator main{} [];
```

```trendy,error
var teams := relation { { team: "core", members: relation { { name: "Ada" } } } };
var memberships := teams ungroup members;

operator main{} [];
```

```trendy,error
var births := relation { { name: "Ada", born: 1815, place: "London" } };
var nested := births group [names := {name}, years := {born}];

operator main{} [];
```

The suggestion replaces both the opening and the closing delimiter, or
chains the operator:

```trendy
operator main{} [];

var a := relation { { x: 1 } };
var b := join{a, a};

var births := relation { { name: "Ada", born: 1815, place: "London" } };
var nested := births group { names := {name} } group { years := {born} };
var teams := relation { { team: "core", members: relation { { name: "Ada" } } } };
var memberships := teams ungroup {members};
```
