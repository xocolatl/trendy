# A0046: an `if` that decides nothing

An `if` chooses between two values by its condition. One whose condition
is written `true` or `false` always chooses the same branch, so it is that
branch, which the fix keeps. One whose branches are `true` and `false` is
its condition, or the condition negated, which the fix writes instead.

An `if` statement chooses which of its blocks runs. One whose condition
is written `true` or `false` always runs the same one, so the fix keeps
its statements, or removes the `if` if it runs none. An empty block runs
nothing: the fix removes an empty `else`, runs the `else` block's
statements under the negated condition for an empty `then`, and removes
an `if` whose blocks are all empty.

```trendy,error
operator label{n: integer}: text [
    if true then "many" else "one"
];

operator main{} [];
```

```trendy,error
operator positive{n: integer}: boolean [
    if n > 0 then true else false
];

operator main{} [];
```

```trendy,error
operator negative{n: integer}: boolean [
    if n >= 0 then false else true
];

operator main{} [];
```

```trendy,error
operator report{n: integer} [
    if false then [
        call debug_value{v: n};
    ];
];

operator main{} [];
```

```trendy,error
operator report{n: integer} [
    if n > 0 then [] else [
        call debug_value{v: n};
    ];
];

operator main{} [];
```

A condition known when compiling only from the values of variables, as
`capped`'s below, decides as any other does, and isn't an error. Write
the value itself:

```trendy
var limit := 3;

operator label{n: integer}: text [
    "many"
];

operator positive{n: integer}: boolean [
    n > 0
];

operator negative{n: integer}: boolean [
    not (n >= 0)
];

var capped := if limit > 0 then 3 else 0;

operator report{n: integer} [
    if not (n > 0) then [
        call debug_value{v: n};
    ];
];

operator main{} [];
```
