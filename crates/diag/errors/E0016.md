# E0016: `*/` outside a comment

`*/` closes a comment, so it can only appear inside one. It is usually left
over after removing a comment's `/*`, or an extra one after a comment that
was already closed. The fix removes it.

```trendy,error
var answer := 42; /* the answer */ */

operator main{} [];
```

Remove it, or add the missing `/*`:

```trendy
var answer := 42; /* the answer */

operator main{} [];
```
