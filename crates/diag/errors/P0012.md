# P0012: unterminated comment

A comment starts with `/*` and ends with `*/`. Comments nest: a `/*` inside
a comment starts a nested comment, which needs its own `*/`, so that code
containing comments can itself be commented out. A comment without its
`*/` runs to the end of the file.

```trendy,error
/* the answer /* not yet
var answer := 42;

operator main{} [];
```

The error points at the comment that isn't closed, and at each nested
comment inside it that isn't either. Close each one:

```trendy
/* the answer /* not yet */ */
var answer := 42;

operator main{} [];
```
