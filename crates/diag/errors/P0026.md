# P0026: result type written another way

A read-only operator's result type follows its parameters after `:`, as a
variable's type follows its name: `operator double{x: integer}: integer`.
Other languages' spellings, `-> integer` and Tutorial D's
`RETURNS INTEGER`, are fixed to it.

```trendy,error
operator double{x: integer} -> integer [
    return x * 2;
];

operator main{} [];
```

```trendy
operator double{x: integer}: integer [
    return x * 2;
];

operator main{} [];
```
