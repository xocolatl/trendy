# P0011: attribute separator

In a tuple type or a tuple value, an attribute's name is followed by `:`,
then its type or value: `tuple { x: rational }` and `tuple { x: 1.0 }`. The
`=` of keyword arguments and the `:=` of assignment are not used here.

```trendy,error
var origin := tuple { x = 0.0, y = 0.0 };

operator main{} [];
```

Write `:` after each attribute name:

```trendy
var origin := tuple { x: 0.0, y: 0.0 };

operator main{} [];
```
