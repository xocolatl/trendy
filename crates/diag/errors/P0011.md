# P0011: attribute separator

In a tuple type or a tuple value, an attribute's name is followed by `:`,
then its type or value: `tuple { x: approximate }` and `tuple { x: 1e0 }`. The
`=` of keyword arguments and the `:=` of assignment are not used here.

In an `extend`, each new attribute is defined by a value computed from the
tuple, so it is written as a definition is, with `:=`:
`r extend { total := price * quantity }`. The `:` of a tuple and the `=` of
keyword arguments are fixed to `:=`, and `value as name`, as SQL's
`SELECT … AS` and Tutorial D's `EXTEND … ADD` write it, to `name := value`.
A `replace` gives existing attributes new values, written the same way:
`r replace { price := price * 2 }`; there, SQL's `SET price = …` is fixed
too.

```trendy,error
var origin := tuple { x = 0e0, y = 0e0 };

operator main{} [];
```

```trendy,error
var items := relation { { price: 3, quantity: 4 } };
var totals := items extend { total: price * quantity };

operator main{} [];
```

```trendy,error
var items := relation { { price: 3, quantity: 4 } };
var totals := items extend { price * quantity as total };

operator main{} [];
```

```trendy,error
var items := relation { { price: 3, quantity: 4 } };
var doubled := items replace { price = price * 2 };

operator main{} [];
```

Write `:` after each attribute name in a tuple, and `:=` in an `extend` or
a `replace`:

```trendy
var origin := tuple { x: 0e0, y: 0e0 };
var items := relation { { price: 3, quantity: 4 } };
var totals := items extend { total := price * quantity };
var doubled := items replace { price := price * 2 };

operator main{} [];
```
