# E0113: built-in operator outside the prelude

`builtin operator` declares an operator that the compiler implements. Those
declarations belong to the prelude, which is part of the compiler and is
always in scope, so a program never declares built-ins itself: it can call
`debug_value` directly. To define an operator of your own, give it a body.

```trendy,error
builtin operator show{v: integer};

operator main{} [];
```

Define the operator with a body instead:

```trendy
operator show{v: integer} [
    call debug_value{v: v};
];

operator main{} [];
```
