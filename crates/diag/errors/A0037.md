# A0037: `call` of a read-only operator

`call` invokes an update operator, which returns nothing. A read-only
operator's call is a value, which `call` would lose, so it goes in an
expression, where the value is used.

```trendy,error
operator double{x: integer}: integer [
    return x * 2;
];

operator main{} [
    call double{x: 21};
];
```

Use the value:

```trendy
operator double{x: integer}: integer [
    return x * 2;
];

operator main{} [
    call debug_value{v: double{x: 21}};
];
```
