# P0018: renaming written with `:`

`rename` takes renamings, each written `old as new`, as in Tutorial D and
SQL. Mappings in other languages, such as pandas'
`{'postal_code': 'code'}`, use a colon, and disagree about which side is
which; `as` leaves no doubt. The fix reads the colon as `old: new`, the most
common habit, so check that it's the direction meant.

```trendy,error
var addr := tuple { postal_code: "75001" };
var moved := addr rename {postal_code: code};

operator main{} [];
```

Write `as`, with the name the attribute has now first:

```trendy
var addr := tuple { postal_code: "75001" };
var moved := addr rename {postal_code as code};

operator main{} [];
```
