# P0018: renaming written with `:`

`rename` takes renamings, each written `old as new`, as in Tutorial D and
SQL. Mappings in other languages, such as pandas' `{'zip': 'postcode'}`,
use a colon, and disagree about which side is which; `as` leaves no doubt.
The fix reads the colon as `old: new`, the most common habit, so check
that it's the direction meant.

```trendy,error
var addr := tuple { zip: "20500" };
var moved := addr rename {zip: postcode};

operator main{} [];
```

Write `as`, with the name the attribute has now first:

```trendy
var addr := tuple { zip: "20500" };
var moved := addr rename {zip as postcode};

operator main{} [];
```
