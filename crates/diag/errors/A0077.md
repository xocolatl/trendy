# A0077: an initial value computed only when the program runs

A program variable's initial value is known when compiling. A value block
or a read-only operator's body with an `if` statement, a loop, a
transaction or a `fail` statement runs those statements when the program
runs, and never when compiling, as they may not stop. And so does an operator
that calls itself, directly or through others. So an initial value can't have
such a block or call such an operator, directly or through another, and neither
can one select a value of a type whose constraint does:

```trendy,error
operator countdown{n: integer}: integer [
    if n = 0 then 0 else countdown{n: n - 1}
];

var left := countdown{n: 3};

operator main{} [];
```

```trendy,error
operator doubling{n: integer}: integer [
    var at := 1;
    while at < n loop [
        at := at * 2;
    ];
    at
];

var size := doubling{n: 100};

operator main{} [];
```

```trendy,error
operator doubling{n: integer}: integer [
    var at := 1;
    while at < n loop [
        at := at * 2;
    ];
    at
];

operator padded{n: integer}: integer [
    doubling{n: n} + 1
];

var size: integer := padded{n: 100};

operator main{} [];
```

```trendy,error
var size := [
    var at := 1;
    while at < 100 loop [
        at := at * 2;
    ];
    at
];

operator main{} [];
```

Declare the variable with its type, and assign it in `main`, or anywhere
else that runs:

```trendy
operator doubling{n: integer}: integer [
    var at := 1;
    while at < n loop [
        at := at * 2;
    ];
    at
];

var size: integer;

operator main{} [
    size := doubling{n: 100};
    call debug_value{v: size};
];
```
