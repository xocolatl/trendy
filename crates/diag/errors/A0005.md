# A0005: integer literal out of range

Integers are 64-bit signed, so integer literals range from
`-9223372036854775808` to `9223372036854775807`.

```trendy,error
var big: integer := 9223372036854775808;

operator main{} [];
```

Use a value in range:

```trendy
var big: integer := 9223372036854775807;

operator main{} [];
```
