# E0008: invalid integer literal

Integer literals are written in decimal with ASCII digits only, such as `42`.
Digit separators (`1_000`) and radix prefixes (`0x1F`, `0o17`, `0b101`) are
not supported. When the intended value is clear, the fix rewrites the literal
in decimal.

```trendy,error
var million: integer := 1_000_000;

operator main{} [];
```

```trendy,error
var mask: integer := 0xFF;

operator main{} [];
```

Write the value in decimal:

```trendy
var million: integer := 1000000;
var mask: integer := 255;

operator main{} [];
```
