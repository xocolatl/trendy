# A0050: an initial value reads input

A variable of the program starts with its initial value, which is
computed when compiling, so that the program starts with every variable
already holding its value. Input, such as a file `load_text_file` reads,
is known only when the program runs, so an initial value can't read any,
whether it calls `load_text_file` itself or calls an operator that does.

```trendy,error
var lines := load_text_file{path: "rivers.txt"};

operator main{} [];
```

```trendy,error
operator rivers{}: array text [
    load_text_file{path: "rivers.txt"}
];

var lines := rivers{};

operator main{} [];
```

Read it in an operator that runs when the program does, such as `main`:
into a local variable, or into a variable of the program declared with
its type, which then starts empty.

```trendy
var lines: array text;

operator main{} [
    lines := load_text_file{path: "rivers.txt"};
    call debug_value{v: lines};
];
```
