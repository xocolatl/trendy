# P0002: missing token

A definition is incomplete: the parser reached a token that cannot come next,
so something is missing before it. The error points at the exact place where
the missing text belongs, and when the missing text is fixed punctuation or a
keyword, the suggestion inserts it.

An operator definition has the form `operator name{} [];`: the keyword, a
name, a parameter list in `{}`, a body in `[]`, and a closing `;`.

```trendy,error
operator main{} []
```

```trendy,error
operator main [];
```

Insert what is missing:

```trendy
operator main{} [];
```

A statement ends with `;`. Before something that can't start another
statement, as the `2` in `n := 1 2;`, a `;` alone wouldn't make the code
right, and after a value an operator may be what's missing, as in
`1 + 2`, so nothing is inserted. Where a statement should start but
can't, as before the `,` in `[ , n := 1; ]`, one is missing.

```trendy,error
var n := 0;

operator main{} [
    n := 1 2;
];
```

Join the operands with an operator, or end the statement after the first:

```trendy
var n := 0;

operator main{} [
    n := 1 + 2;
];
```
