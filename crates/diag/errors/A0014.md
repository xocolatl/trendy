# A0014: `any` outside a built-in operator

`any` is a reserved type name, used only in the prelude's declarations of
built-in operators such as `debug_value{v: any}`, which accept a value of
every type. No value has type `any`, so variables and the parameters of your
own operators need specific types. A *variable* named `any` is fine, since
types and values have separate namespaces.

```trendy,error
var x: any := 1;

operator main{} [];
```

```trendy,error
operator show{v: any} [];

operator main{} [];
```

Give a specific type:

```trendy
var x: integer := 1;
var any := 2;

operator show{v: integer} [];

operator main{} [];
```
