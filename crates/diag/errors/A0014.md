# A0014: `any type` outside a parameter's type

`any type`, `any tuple` and `any relation` are only a parameter's type:
each call of the operator gives the parameter the type of its argument.
Nothing would give one written anywhere else a type, so a variable's type
is always a specific one, and an operator's result type is either specific
or made of the operator's type parameters.

```trendy,error
var x: any type := 1;

operator main{} [];
```

```trendy,error
operator first{r: relation { v: T }}: any type
    types { T: any type }
[
    value from r
];

operator main{} [];
```

Give a variable a specific type, and make a result's type a type
parameter that is also in a parameter's type, so that the call's argument
gives it its type:

```trendy
var x: integer := 1;

operator first{r: relation { v: T }}: T
    types { T: any type }
[
    value from r
];

operator main{} [];
```
