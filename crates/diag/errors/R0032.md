# R0032: standard input can't be read

`read`, of `trendy.streams`, reads standard input when the program runs, and
the program stops if the system can't: if the program was started with it
closed, as a shell does when told `<&-`, or with it a directory, as `< /`
does. It writes the system's reason to stderr, as in `error[R0032]: can't
read standard input: Bad file descriptor`, and exits with status 1. A call
that names `out errors` gives an `unreadable_input { reason }` there instead.

The compiler never reads standard input, so this is reported only when the
program runs:

```trendy
uses { trendy.streams };

operator main{} [
    var lines: array text;
    call read{out lines};
    call write{line: to_text{from: length{a: lines}}};
];
```

Start the program with standard input open, from a file, a pipe or a
terminal.
