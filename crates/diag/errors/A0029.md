# A0029: compose of nothing

`compose[r, s, t]` composes from the left: it is `(r compose s) compose t`.
Brackets enclose it because the order matters, since compose isn't
associative. `compose[r]` is `r`, but `compose[]` has no value.
`join{}` and `times{}` are `relation {} { {} }`, which joins with any
relation to give it back. Nothing composes with every relation that way,
since compose needs a common attribute and removes it.

```trendy,error
var nothing := compose[];

operator main{} [];
```

Write the relations to compose:

```trendy
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var continents := relation { { continent: "Africa", area: 30370000 } };
var areas := compose[cities, countries, continents];

operator main{} [];
```
