# A0029: an operator's list with nothing in it

An operator of a list has a value with no operands only if it has an
identity: `join{}` and `times{}` are `relation {} { {} }`, which joins
with anything to give it back. The others have none:

- `compose[r, s, t]` composes from the left, and no relation composes
  with everything to give it back, since compose needs a common
  attribute and removes it.
- `union{}` would have no heading to be a relation of.
- `intersect{}` would be every tuple of a heading, which isn't known, and
  is usually infinite.
- `d_union{}` and `xunion{}` are unions too.
- `minus[r, s, t]` and `i_minus[r, s, t]` remove from `r`, so they need
  an `r`.

```trendy,error
var nothing := compose[];

operator main{} [];
```

```trendy,error
var nothing := union{};

operator main{} [];
```

A load's order lists at least one attribute: a relation's tuples have no
order, so a load says which to put them in.

```trendy,error
var poets := relation { { name: "Ada" }, { name: "Bashō" } };

operator main{} [
    var names: array text;
    load names from poets order [];
];
```

With one operand, the list is that operand. Write the relations to
combine, and the attributes to order by:

```trendy
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var continents := relation { { continent: "Africa", area: 30370000 } };
var areas := compose[cities, countries, continents];
var all := union{cities, cities};

operator main{} [
    var names: array text;
    load names from cities{city} order [asc city];
];
```
