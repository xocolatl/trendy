# A0029: compose of a list of operands

`join{r, s, t}` and `times{r, s, t}` join any number of relations, because
join is associative and commutative: however the operands are grouped and
ordered, the result is the same. Compose isn't associative.
`(r compose s) compose t` removes the attributes `r` and `s` share before
`t` is matched, and `r compose (s compose t)` those `s` and `t` share, so
the two can differ, and `compose{r, s, t}` would have no one meaning. So
compose takes exactly two operands, written `r compose s`. With two, the fix
writes that.

```trendy,error
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var continents := compose{cities, countries};

operator main{} [];
```

```trendy,error
var a := relation { { x: 1, y: 2 } };
var b := relation { { y: 2, z: 3 } };
var c := relation { { z: 3, w: 4 } };
var d := compose{a, b, c};

operator main{} [];
```

Write `compose` between two operands, and parenthesize the order you mean:

```trendy
var cities := relation { { city: "Kumasi", country: "Ghana" } };
var countries := relation { { country: "Ghana", continent: "Africa" } };
var continents := cities compose countries;

var a := relation { { x: 1, y: 2 } };
var b := relation { { y: 2, z: 3 } };
var c := relation { { z: 3, w: 4 } };
var d := (a compose b) compose c;

operator main{} [];
```
