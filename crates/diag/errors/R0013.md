# R0013: a file isn't UTF-8 text

A `text` value is Unicode, encoded as UTF-8, so `load_text_file` reads
only a file that is UTF-8 text. When the program runs, it stops at the
first line that isn't, writing the line's number and the path to stderr,
as in `error[R0013]: line 3 of "rivers.txt" isn't UTF-8 text`, and exits
with status 1. A file in another encoding, such as Latin-1 or UTF-16, has
to be converted first, with a tool such as `iconv`, as in
`iconv -f LATIN1 -t UTF-8 rivers.txt > rivers-utf8.txt`.

The compiler never opens the file, so this is reported only when the
program runs:

```trendy
operator main{} [
    var lines := load_text_file{path: "rivers-utf8.txt"};
    call debug_value{v: lines};
];
```
