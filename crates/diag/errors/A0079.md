# A0079: a projection or a call

A name alone in braces is its own value, so `f{a, b}` calls the operator `f`
with `a: a` and `b: b`, and `r{a, b}` projects the relation `r` on its
attributes `a` and `b`. Usually only one fits. When `f` names both a value with
those attributes and an operator with exactly those parameters, and `a` and `b`
each name a value, nothing says which is meant:

```trendy,error
var totals := relation { { year: 2024, region: "Lima" } };

operator totals{year: integer, region: text}: integer [ year ];

operator show{year: integer, region: text} [
    call debug_value{v: totals{year, region}};
];

operator main{} [];
```

Write out the call, or put the value in parentheses for the projection:

```trendy
var totals := relation { { year: 2024, region: "Lima" } };

operator totals{year: integer, region: text}: integer [ year ];

operator show{year: integer, region: text} [
    call debug_value{v: totals{year: year, region: region}};
    call debug_value{v: (totals){year, region}};
];

operator main{} [];
```
