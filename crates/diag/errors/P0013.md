# P0013: missing `call`

A statement invokes an update operator, and starts with `call`. As in *The
Third Manifesto*, operators are either read-only operators, which return a
value and are used in expressions, or update operators, which return nothing
and are invoked by a `call` statement. Built-ins such as `debug_value` are
update operators.

```trendy,error
operator main{} [
    debug_value{v: 1};
];
```

Start the statement with `call`:

```trendy
operator main{} [
    call debug_value{v: 1};
];
```
