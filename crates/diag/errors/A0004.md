# A0004: mismatched types

A variable's initial value must have the variable's declared type. `true` and
`false` have type `boolean`, integer literals have type `integer`, approximate
literals (with an exponent) have type `approximate`, and
text literals have type `text`. As *The Third Manifesto* requires, no value
converts to another type implicitly, not even an integer to an approximate
number. A literal is written as one of the type instead, and other values
converted with `to_text` and `to_approximate`, which the fixes call:

```trendy,error
operator label{city: text, people: integer} [
    call debug_value{v: city || ": " || people};
];

operator average{total: approximate, count: integer} [
    call debug_value{v: total / count};
];

operator main{} [];
```

```trendy,error
var count: integer := "5";

operator main{} [];
```

```trendy,error
var name: text := 5;

operator main{} [];
```

```trendy,error
var ratio: approximate := 1;

operator main{} [];
```

```trendy,error
var enabled: boolean := 1;

operator main{} [];
```

An operator such as `/` or `||` gives a value of its operands' type, so the
type expected of its result is expected of each operand. Only that operand
is wrong, and the declared type isn't offered as a fix, since the other
operands wouldn't fit it:

```trendy,error
operator density{people: integer, km2: approximate}: approximate [
    people / km2
];

operator main{} [];
```

A `replace` keeps each attribute's type, so a new value must have the type
of the attribute it replaces:

```trendy,error
var item := tuple { name: "tea", price: 3 };
var doubled := item replace { price := price * 2e0 };

operator main{} [];
```

A value of a subtype of a union type is a value of the union type too,
so it can be given where one of the union type is expected, but not the
other way round: a value of the union type can be of any of its subtypes
(*Type Inheritance and Relational Theory*, chapter 12). Nor are two of its
subtypes' values ever equal, since no value is of both:

```trendy,error
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

var lake := ellipse{a: 3e0, b: 2e0};
var figure: plane_figure := lake;
var oval: ellipse := figure;
var same := lake = polygon{corners: 4};

operator main{} [];
```

Write a value of the declared type, converting one with `to_text` or
`to_approximate`. To change an attribute's type, compute it under another
name with `extend`, then remove the old one and rename the new:

```trendy
var count: integer := 5;
var name: text := "5";
var ratio: approximate := 1e0;
var enabled: boolean := true;
var item := tuple { name: "tea", price: 3 };
var doubled := item replace { price := price * 2 };
var priced := item extend { new_price := tuple { amount: price, currency: "EUR" } } remove {price} rename {new_price as price};
var stock := relation { { item: "tea", count: 3 } };

operator positive{r: any relation, of: integer per r}: relation { of: integer } [
    (r where of > 0){of}
];

var counted := positive{r: stock, of: count};

operator label{city: text, people: integer} [
    call debug_value{v: city || ": " || to_text{from: people}};
];

operator average{total: approximate, count: integer} [
    call debug_value{v: total / to_approximate{from: count}};
];

operator density{people: integer, km2: approximate}: approximate [
    to_approximate{from: people} / km2
];

operator main{} [];
```
