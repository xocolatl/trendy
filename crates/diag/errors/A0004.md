# A0004: mismatched types

A variable's initial value must have the variable's declared type. `true` and
`false` have type `boolean`, integer literals have type `integer`, approximate
literals (with an exponent) have type `approximate`, and
text literals have type `text`. As *The Third Manifesto* requires, no value
converts to another type implicitly, not even an integer to an approximate
number.

```trendy,error
var count: integer := "5";

operator main{} [];
```

```trendy,error
var name: text := 5;

operator main{} [];
```

```trendy,error
var ratio: approximate := 1;

operator main{} [];
```

```trendy,error
var enabled: boolean := 1;

operator main{} [];
```

A `replace` keeps each attribute's type, so a new value must have the type
of the attribute it replaces:

```trendy,error
var item := tuple { name: "tea", price: 3 };
var doubled := item replace { price := price * 2e0 };

operator main{} [];
```

Write a value of the declared type. To change an attribute's type, compute
it under another name with `extend`, then remove the old one and rename the
new:

```trendy
var count: integer := 5;
var name: text := "5";
var ratio: approximate := 1e0;
var enabled: boolean := true;
var item := tuple { name: "tea", price: 3 };
var doubled := item replace { price := price * 2 };
var priced := item extend { new_price := tuple { amount: price, currency: "EUR" } } remove {price} rename {new_price as price};

operator main{} [];
```
