# P0004: expected a definition

Something at the top level of the file is not a definition. Every top-level
item is either an operator definition, which starts with `operator`, or a
variable declaration, which starts with `var`. Keywords from other languages,
such as `fn`, `def`, `void`, `let` or `const`, are not used. When the rest
looks like a definition, the fix replaces the keyword.

```trendy,error
fn main{} [];
```

```trendy,error
void main() {}
```

```trendy,error
let count: integer := 0;

operator main{} [];
```

Start each definition with `operator` or `var`:

```trendy
var count: integer := 0;

operator main{} [];
```
