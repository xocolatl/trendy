# P0004: expected a definition

Something at the top level of the file is not a definition. Every top-level
item is an operator definition, which starts with `operator`, a variable
declaration, which starts with `var`, or a heading declaration, which
starts with `heading`. Keywords from other languages, such as `fn`, `def`,
`void`, `let` or `const`, are not used. When the rest looks like a
definition, the fix replaces the keyword. In a body, or a value block, a
local variable is declared with `var` too, and `let x = 1;` is fixed to
`var x := 1;`.

A type of records, as TypeScript declares one with `type` or `interface`,
and C and Rust with `struct`, is a heading in trendy: the attributes of
tuples and relations alike. Its declaration is fixed to a heading's,
whose types are `relation home` and `tuple home`.

```trendy,error
fn main{} [];
```

```trendy,error
void main() {}
```

```trendy,error
let count: integer := 0;

operator main{} [];
```

```trendy,error
interface Home {
    city: text,
    rooms: integer,
}

operator main{} [];
```

```trendy,error
operator main{} [
    let count = 0;
    call debug_value{v: count};
];
```

Start each definition with `operator`, `var` or `heading`:

```trendy
heading home := { city: text, rooms: integer };

var count: integer := 0;

operator main{} [];
```
