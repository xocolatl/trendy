# R0011: an array's index out of range

An array's elements are at positions 1 up to its length, counting from 1
as SQL and Tutorial D do, so the first element of `a` is `a[1]` and the
last is `a[length{a: a}]`. A position outside that range has no element,
to read, or to give a new value: `a[i] := x` changes an element, and never
adds one.

When the array and the position are known while compiling, it is reported
there, as is a position below 1 whatever the array:

```trendy,error
var rainfall := array [1200, 950, 220];
var fourth := rainfall[4];

operator main{} [];
```

```trendy,error
var rainfall := array [1200, 950, 220];
var first := rainfall[0];

operator main{} [];
```

When either is known only when the program runs, the program stops at the
index, or the assignment, instead, writing `error[R0011]: an array has no
element at that position` to stderr and exiting with status 1.

Index from 1 up to the array's length:

```trendy
var rainfall := array [1200, 950, 220];
var first := rainfall[1];
var last := rainfall[length{a: rainfall}];

operator main{} [];
```
