# A0026: assigning something that isn't a variable

Only variables, declared with `var`, are assigned, with `:=` or a
shorthand such as `insert`, and the elements of array variables, as in
`a[i] := x`, which assigns `a`.

An operator's parameters are read-only: an operator can't change the
arguments it is passed. A parameter with the same name as a variable hides
it, so assigning that name assigns the parameter, which is an error too.

```trendy,error
var visits := 0;

operator record{visits: integer} [
    visits := visits + 1;
];

operator main{} [];
```

An operator isn't a value at all, so it can't be assigned either:

```trendy,error
operator main{} [
    main := 1;
];
```

A `for` loop's variable takes each element's value in turn, so the block
can't assign it, nor any variable the loop's array is computed from, nor
an element of one: the array doesn't change while the loop runs, so the
loop never goes past the end of one that shrinks. Nor can the block call
an update operator that assigns one, in its body or through the operators
it calls:

```trendy,error
var queue := array ["Amara", "Kofi"];

operator reset{} [
    queue := array ["Wanjiru"];
];

operator serve{} [
    for name in queue loop [
        call reset{};
        call debug_value{v: name};
    ];
];

operator main{} [];
```

```trendy,error
var rainfall := array [1200, 950, 220];

operator main{} [
    for r in rainfall loop [
        rainfall[1] := r;
    ];
];
```

Rename the parameter, so that the variable can be assigned, or declare a
variable for the value to keep; assign what a loop goes through after it,
or go through the positions with a `while` loop, which reads the array
anew each time:

```trendy
var visits := 0;

operator record{added: integer} [
    visits := visits + added;
];

var queue := array ["Amara", "Kofi"];

operator reset{} [
    queue := array ["Wanjiru"];
];

operator serve{} [
    for name in queue loop [
        call debug_value{v: name};
    ];
    call reset{};
];

var rainfall := array [1200, 950, 220];

operator double{} [
    var i := 1;
    while i <= length{a: rainfall} loop [
        rainfall[i] := rainfall[i] * 2;
        i := i + 1;
    ];
];

operator main{} [
    call record{added: 1};
];
```
