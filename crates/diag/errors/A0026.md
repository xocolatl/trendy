# A0026: assigning something that isn't a variable

Only variables, declared with `var` at the top level, are assigned, with
`:=` or a shorthand such as `insert`.

An operator's parameters are read-only: an operator can't change the
arguments it is passed. A parameter with the same name as a variable hides
it, so assigning that name assigns the parameter, which is an error too.

```trendy,error
var visits := 0;

operator record{visits: integer} [
    visits := visits + 1;
];

operator main{} [];
```

An operator isn't a value at all, so it can't be assigned either:

```trendy,error
operator main{} [
    main := 1;
];
```

Rename the parameter, so that the variable can be assigned, or declare a
variable for the value to keep:

```trendy
var visits := 0;

operator record{added: integer} [
    visits := visits + added;
];

operator main{} [
    call record{added: 1};
];
```
