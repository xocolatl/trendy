# E0110: unknown attribute

A tuple value has an attribute that its declared type doesn't. When the name
is close to an attribute the value is missing, the fix renames it; otherwise
the fix removes it.

```trendy,error
var point: tuple { x: rational, y: rational } := tuple { x: 1.0, why: 2.0 };

operator main{} [];
```

```trendy,error
var point: tuple { x: rational } := tuple { x: 1.0, z: 3.0 };

operator main{} [];
```

Use only the declared attributes:

```trendy
var point: tuple { x: rational, y: rational } := tuple { x: 1.0, y: 2.0 };
var flat: tuple { x: rational } := tuple { x: 1.0 };

operator main{} [];
```
