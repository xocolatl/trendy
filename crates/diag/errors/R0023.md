# R0023: a constraint broken

A constraint, `constraint name := condition;`, is a condition on a
unit's variables that holds whenever a statement ends, so no statement
can leave them in a state that breaks it (TTM RM Prescription 23). It
holds of the variables' initial values too, which are known when
compiling, so a constraint they break is reported then:

```trendy,error
var countries := relation { { country: "Kenya" } } key { country };
var official := relation {
    { language: "Swahili", country: "Kenya" },
    { language: "Quechua", country: "Peru" },
}
key { language, country };

constraint known_countries := official{country} <= countries;

operator main{} [];
```

The error says what breaks it where its form says which:

- `a <= b`: the tuples of `a` that aren't in `b`, and for `a >= b`, those
  of `b` that aren't in `a`. This is the shape of a foreign key: every
  country a language is official in is a country there is.
- `is_empty{r: e}`: the tuples of `e`.
- `c and d`: whichever of `c` and `d` is false, each with what breaks it.

Otherwise it says that the condition is false. Change the initial values,
or the constraint, so that it holds:

```trendy
var countries := relation { { country: "Kenya" }, { country: "Peru" } } key { country };
var official := relation {
    { language: "Swahili", country: "Kenya" },
    { language: "Quechua", country: "Peru" },
}
key { language, country };

constraint known_countries := official{country} <= countries;

operator main{} [];
```
