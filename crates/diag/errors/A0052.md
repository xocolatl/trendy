# A0052: an argument marked with another mode than its parameter's

A call marks each argument for a `var` parameter `var`, before its name,
as the parameter is: the call updates that variable, and a reader of the
call sees which arguments change without looking up the operator. An
argument for a `const` parameter, which the operator only reads, may be
marked `const`, or not at all, but not `var`.

```trendy,error
var count := 1;

operator double{var n: integer} [
    n := n * 2;
];

operator main{} [
    call double{n: count};
];
```

```trendy,error
operator show{n: integer} [
    call debug_value{v: n};
];

var count := 1;

operator main{} [
    call show{var n: count};
];
```

Mark each argument as its parameter is:

```trendy
var count := 1;

operator double{var n: integer} [
    n := n * 2;
];

operator show{n: integer} [
    call debug_value{v: n};
];

operator main{} [
    call double{var n: count};
    call show{n: count};
];
```
