# P0008: invalid integer literal

An integer literal is decimal digits, such as `42`, or a radix prefix,
`0x`, `0o` or `0b`, in lower case, and hexadecimal, octal or binary
digits, such as `0xFF`, `0o755` or `0b1010`. A hexadecimal digit after 9
is a letter from `a` to `f`, in either case. An underscore between two
digits separates them, as in `1_000_000` or `0xFFFF_FFFF`, and stands
for nothing. Where an underscore isn't between two digits, the fix
leaves it out, and an upper-case prefix, the fix writes in lower case:

```trendy,error
var million := 1__000_000_;
var mask := 0XFF;

operator main{} [];
```

A decimal number has no leading zero, since C reads `0755` as octal, 493,
and a decimal number would quietly differ from it. Which was meant isn't
certain, so the help shows both:

```trendy,error
var mode := 0755;

operator main{} [];
```

A digit outside the radix is pointed at:

```trendy,error
var flags := 0b1012;

operator main{} [];
```

Write each digit of the radix, and each underscore between two:

```trendy
var million := 1_000_000;
var mask := 0xFF;
var mode := 0o755;
var flags := 0b1011;

operator main{} [];
```
