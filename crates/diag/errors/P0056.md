# P0056: a database written as another language writes it

A database is declared `database name;`, and its units add each relvar and
each constraint to it, named after it: `var name.pantry: relation { … };`
and `constraint name.stocked := …;`.

```trendy
database kitchen;

var kitchen.pantry: relation { item: text, grams: integer } key { item };

operator main{} [];
```

SQL's `CREATE DATABASE name` is fixed to that, and a variable of the
program's is private already, so Tutorial D's `PRIVATE` before a relvar's
type is removed:

```trendy,error
CREATE DATABASE kitchen;

var shopping private relation { item: text };

operator main{} [];
```

SQL's `CREATE SCHEMA` is reported with help, as a schema keeps some of a
database's names apart from the others, which units do, and Tutorial D's
`REAL`, `BASE` and `PUBLIC` relvars with help, as a database's relvar is
declared with its database's name:

```trendy,error
create schema kitchen;

var pantry real relation { item: text };

operator main{} [];
```
