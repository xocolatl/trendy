# A0007: approximate literal out of range

`approximate` values are 64-bit IEEE 754 binary floating-point numbers, so a
literal whose magnitude is larger than about `1.8e308` can't be represented.
Very small literals are rounded instead, to the nearest representable value
or zero.

```trendy,error
var huge: approximate := 1e400;

operator main{} [];
```

Use a value in range:

```trendy
var huge: approximate := 1e300;

operator main{} [];
```
