# R0015: a file isn't CSV

`load_csv` reads a file as CSV, as RFC 4180 has it: records separated by
line ends, a line feed or a carriage return and a line feed, and fields
separated by commas. A field with a comma, a quote or a line end is in
quotes, and each quote in it is doubled: `"Hanoi, ""Hà Nội"""` is the
text `Hanoi, "Hà Nội"`. Empty lines are skipped.

When the program runs, it stops at the first line of the file that
isn't CSV, writing the line's number and the path to stderr, and exits
with status 1:

- a quote in a field that isn't quoted, as in `Lima "Peru",1`, which is
  written `"Lima ""Peru""",1`;
- more after a quoted field's closing quote than a comma or a line end,
  as in `"Lima"x,1`;
- a quoted field that isn't closed, which the file ends in;
- a record with another number of fields than the header, as in
  `error[R0015]: line 3 of "cities.csv" has 3 fields, but the header has
  4`, often a field with a comma that isn't in quotes.

The compiler never opens the file, so this is reported only when the
program runs:

```trendy
operator main{} [
    var rows: array tuple { city: text, people: integer };
    call load_csv{path: "cities.csv", out rows: rows};
    call debug_value{v: rows};
];
```
