# A0062: a type test or a treat that decides nothing

`x is t` is true if the value of `x` is of the type `t`, or of one of its
subtypes (*Type Inheritance and Relational Theory*, IM Prescription 15), so
it tells a union type's values apart: in the rest of a condition, `x` is
then a `t`. A test for a type the value is always of, or never, decides
nothing, and is an error:

```trendy,error
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

operator always{e: ellipse}: boolean [ e is plane_figure ];
operator never{e: ellipse}: boolean [ e is polygon ];

operator main{} [];
```

A tuple's, a relation's or an array's type is known when compiling, so
`is` tests the values in it instead, as in `t.figure is ellipse`.

So with `treat x as t`, the value of `x` as one of `t`, a subtype of its
type, which fails unless it is one (IM Prescription 14): a treat that
always succeeds, to the value's own type or a supertype of it, or never,
to a type it can't be of, is an error:

```trendy,error
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

operator always{e: ellipse}: approximate [ (treat e as ellipse).a ];

operator main{} [];
```

Test a value of the union type for one of its subtypes:

```trendy
type plane_figure union;
type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

operator wide{f: plane_figure}: boolean [ f is ellipse and f.a > 2e0 ];

operator main{} [];
```
