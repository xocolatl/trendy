# R0029: an environment variable that isn't UTF-8 text

`trendy.process`'s `environment` is the environment the program is started
with, each variable by its name and its value, both text. On most systems
they are any bytes, but text is UTF-8, so a variable whose name or value
isn't can't be one of them. The program stops before `main` runs, saying
which, so that nothing acts on what it wasn't given, as dropping the
variable or changing its bytes would. Its name is written with each byte
that isn't UTF-8 as `�`, U+FFFD. Only a program that reads or assigns
`environment` is given it, so one that never looks at it can't stop for it.

```trendy
uses { trendy.process };

operator main{} [
    call debug_value{v: environment where name = "LANG"};
];
```

Started with `GREETING` set to `café`, with `é` written as Latin-1's one byte
rather than UTF-8's two, it writes `error[R0029]: the environment variable
GREETING isn't UTF-8 text` to stderr, and exits with status 1. Give the
program UTF-8 text: `iconv` converts what isn't, and `env -u GREETING`
starts it without that variable.
