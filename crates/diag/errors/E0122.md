# E0122: integer overflow

Integers are 64-bit signed, from -9223372036854775808 to
9223372036854775807. An operator whose result is outside that range has no
result: it never wraps around or saturates.

When the operands are known while compiling, the overflow is reported
there:

```trendy,error
var big := 9223372036854775807 + 1;

operator main{} [];
```

`-9223372036854775808 div -1` overflows too, because the quotient would be
9223372036854775808. Negating the smallest integer overflows for the same
reason.

When an operand is known only when the program runs, the program stops at
the overflowing operator instead, writing
`error[E0122]: integer overflow` to stderr and exiting with status 1.

Keep the values in range, or rearrange the computation so that no
intermediate result leaves it:

```trendy
var big := 9223372036854775807 - 1 + 1;

operator main{} [];
```
