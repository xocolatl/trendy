# A0075: a qualifier that names no unit seen

A qualified name, `lakes.depths::metres`, names the unit that declares
it: one the section it is written in uses, by the name its `uses` gives
it after `as`, if it gives one, or else by its own, or the prelude,
`trendy.prelude`, which every unit sees. A unit's own names are never
qualified, since they hide every other unit's, so its own name is
removed by the fix; a unit of the program the section doesn't use is
used by the fix; and a unit used by another name is written by that
name. For the unit `lakes/depths.trendy`:

```trendy,unit lakes.depths
interface

type metres { { m: integer } };
```

```trendy,error
var depth: lakes.depths::metres;

operator main{} [];
```

```trendy,error
uses { lakes.depths as depths };

var depth: lakes.depths::metres;

operator main{} [];
```

Qualify a name by a unit the section uses, by its name there:

```trendy
uses { lakes.depths as depths };

var depth: depths::metres := metres{m: 281};

operator main{} [];
```
