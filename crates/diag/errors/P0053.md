# P0053: a unit's sections out of order

A unit has one interface and one implementation, the interface first:
`interface` starts the declarations other units see, and
`implementation` those they don't. What comes before either header is
the implementation's, so a file without headers exports nothing:

```trendy
interface

operator deepest{depths: relation { m: integer }}: integer;

implementation

operator deepest{depths: relation { m: integer }}: integer [
    max{r: depths, of: m}
];

operator main{} [];
```

A second `implementation` is removed, as what follows it is the
implementation's still, and so is a second `interface` before the
implementation:

```trendy,error
interface

operator deepest{depths: relation { m: integer }}: integer;

implementation

operator deepest{depths: relation { m: integer }}: integer [
    max{r: depths, of: m}
];

implementation

operator main{} [];
```

An interface after the implementation is reported with help: its
declarations move before `implementation`, which the program does:

```trendy,error
implementation

operator main{} [];

interface

operator deepest{depths: relation { m: integer }}: integer;
```
