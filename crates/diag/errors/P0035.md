# P0035: an expression as a statement

A statement does something: it calls an update operator, assigns a
variable, declares a local one, or chooses or repeats other statements.
An expression on its own only computes a value, which nothing would use,
so, unlike in C, JavaScript or Python, it isn't a statement, as it isn't
in Tutorial D, whose statements are assignments, calls and the like (TTM,
Appendix I). To keep the value, assign it; to see it, write it with
`debug_value`. Which of the two is meant can't be told from most
expressions, so most have no fix. In a read-only operator's body, an
expression at the end is the body's value (P0031).

```trendy,error
var total := 0;

operator add{n: integer} [
    total + n;
];

operator main{} [];
```

Assign the value, or write it:

```trendy
var total := 0;

operator add{n: integer} [
    total := total + n;
    call debug_value{v: total};
];

operator main{} [];
```

A variable with `replace`, as in `t replace { a := 2 };`, is fixed to
`update t { a := 2 };`, which assigns the variable the new value:
`replace` is an expression, which leaves its operand as it was.

```trendy,error
var stop := tuple { name: "Mombasa", latitude: -4.05e0 };

operator moved{} [
    stop replace { latitude := 0e0 };
];

operator main{} [];
```

```trendy
var stop := tuple { name: "Mombasa", latitude: -4.05e0 };

operator moved{} [
    update stop { latitude := 0e0 };
];

operator main{} [];
```
