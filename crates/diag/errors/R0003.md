# R0003: out of memory

The program needed memory for a value and the system had none to give.
Values that are computed while the program runs, such as a concatenation
of texts that aren't known when compiling, are stored in memory allocated
for them. When an allocation fails, the program stops, writing
`error[R0003]: out of memory` to stderr and exiting with status 1.

The compiler can't tell in advance whether this will happen, so it is never
reported while compiling. This program allocates only a few bytes:

```trendy
operator greet{name: text} [
    call debug_value{v: "hello, " || name};
];

operator main{} [
    call greet{name: "Ada"};
];
```

If it happens, run the program with more memory available, or make the
values it builds smaller.
