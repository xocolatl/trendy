# A0035: a body's value and `return`

A read-only operator's body has statements, if it has any, on its
parameters and local variables, then ends with its value: an expression
of the operator's result type, without `;`. Without one, the operator has
no value.

`return` leaves an operator from anywhere in its body: a read-only
operator's with its value, `return x;`, of its result type, and an update
operator's without one, `return;`, as it has none. So a read-only operator's
`return` without a value is an error, and so is an update operator's with
one.

A value block is a body in place: its statements, then its value. So
`return` is an error in one, as it would leave the block, not the operator.
And neither a read-only operator nor a value block warns, as a warning
would be written, which is something other than its value.

```trendy,error
operator double{x: integer}: integer [];

operator main{} [];
```

```trendy,error
operator greet{name: text} [
    return "Hello, " || name;
];

operator main{} [];
```

```trendy,error
operator sign{n: integer}: text [
    if n = 0 then [
        return;
    ];
    "positive"
];

operator main{} [];
```

```trendy,error
operator sign{n: integer}: text [
    "a " || [
        var sign := "positive";
        if n < 0 then [
            return "negative";
        ];
        sign
    ]
];

operator main{} [];
```

```trendy,error
operator sign{n: integer}: text [
    warn failure{message: "no sign yet"};
    "positive"
];

operator main{} [];
```

End the body with its value, in an operator with a result type, and return
a value of that type early:

```trendy
operator greeting{name: text}: text [
    "Hello, " || name
];

operator sign{n: integer}: text [
    if n = 0 then [
        return "zero";
    ];
    if n < 0 then "negative" else "positive"
];

operator described{n: integer}: text [
    "a " || [
        var sign := "positive";
        if n < 0 then [
            sign := "negative";
        ];
        sign
    ] || " number"
];

operator digits{n: integer}: integer [
    var left := n;
    var count := 1;
    while left >= 10 loop [
        left := left div 10;
        count := count + 1;
    ];
    count
];

operator greet{name: text} [
    if name = "" then [
        return;
    ];
    call debug_value{v: "Hello, " || name};
];

operator main{} [
    call debug_value{v: greeting{name: "Amara"}};
];
```
