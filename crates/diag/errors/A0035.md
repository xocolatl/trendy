# A0035: a body's value and `return`

A read-only operator's body declares and assigns its local variables, if
it has any, then ends with its value: an expression of the operator's
result type, without `;`. Without one, the operator has no value. It
computes one value, so it chooses between values with an `if` expression,
and has no `if` statements.

`return` is for leaving an operator before the end of its body, which no
operator does yet: a body runs to its end. So `return` before the end of a
read-only operator's body is an error, and so is `return` in an update
operator, which has no value, whether with a value or without. A value
block is the same: it ends with its value, chooses between values with an
`if` expression, and has no `if` statements and no `return`. Neither has
loops, which run statements again: a value is computed from whole
relations at once, as `sum{r: r, of: x}` and `r extend { … }` do.

```trendy,error
operator double{x: integer}: integer [];

operator main{} [];
```

```trendy,error
operator double{x: integer}: integer [
    return x * 2;
    x + x
];

operator main{} [];
```

```trendy,error
operator greet{name: text} [
    return "Hello, " || name;
];

operator main{} [];
```

```trendy,error
operator sign{n: integer}: text [
    var sign := "positive";
    if n < 0 then [
        sign := "negative";
    ];
    sign
];

operator main{} [];
```

End the body with its value, in an operator with a result type:

```trendy
operator double{x: integer}: integer [
    var doubled := x * 2;
    doubled
];

operator greeting{name: text}: text [
    "Hello, " || name
];

operator sign{n: integer}: text [
    if n < 0 then "negative" else "positive"
];

operator main{} [
    call debug_value{v: greeting{name: "Amara"}};
];
```
