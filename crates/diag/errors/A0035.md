# A0035: a read-only operator's `return`

A read-only operator's body declares and assigns its local variables, if it
has any, and ends in one statement, `return value;`, whose value has the
operator's result type. Without a `return` it would have no value, and a
statement after it would never be reached: a second `return` is deleted by
the fix. An update operator, which has no result type, returns no value,
so a `return` in it is an error too.

```trendy,error
operator double{x: integer}: integer [];

operator main{} [];
```

```trendy,error
operator double{x: integer}: integer [
    return x * 2;
    return x + x;
];

operator main{} [];
```

```trendy,error
operator double{x: integer}: integer [
    return x * 2;
    var tripled := x * 3;
];

operator main{} [];
```

```trendy,error
operator greet{name: text} [
    return "Hello, " || name;
];

operator main{} [];
```

Return the value once, at the end, from an operator with a result type:

```trendy
operator double{x: integer}: integer [
    var doubled := x * 2;
    return doubled;
];

operator greeting{name: text}: text [
    return "Hello, " || name;
];

operator main{} [
    call debug_value{v: greeting{name: "Amara"}};
];
```
