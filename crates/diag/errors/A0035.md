# A0035: a read-only operator's `return`

A read-only operator's body is one statement, `return value;`, whose value
has the operator's result type. Without a `return` it would have no value,
and one after another would never be reached; the fix deletes it. An update
operator, which has no result type, returns no value, so a `return` in it
is an error too.

```trendy,error
operator double{x: integer}: integer [];

operator main{} [];
```

```trendy,error
operator double{x: integer}: integer [
    return x * 2;
    return x + x;
];

operator main{} [];
```

```trendy,error
operator greet{name: text} [
    return "Hello, " || name;
];

operator main{} [];
```

Return the value once, from an operator with a result type:

```trendy
operator double{x: integer}: integer [
    return x * 2;
];

operator greeting{name: text}: text [
    return "Hello, " || name;
];

operator main{} [
    call debug_value{v: greeting{name: "Amara"}};
];
```
