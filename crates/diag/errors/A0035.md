# A0035: a body's value and `return`

A read-only operator's body has statements, if it has any, on its
parameters and local variables, then ends with its value: an expression
of the operator's result type, without `;`. Without one, the operator has
no value.

`return` is for leaving an operator before the end of its body, which no
operator does yet: a body runs to its end. So `return` before the end of a
read-only operator's body is an error, and so is `return` in an update
operator, which has no value, whether with a value or without.

A value block is a body in place: its statements, then its value. So
`return` is an error in one too, as it would leave the block, not the
operator. And neither a read-only operator nor a value block warns, as a
warning would be written, which is something other than its value.

```trendy,error
operator double{x: integer}: integer [];

operator main{} [];
```

```trendy,error
operator double{x: integer}: integer [
    return x * 2;
    x + x
];

operator main{} [];
```

```trendy,error
operator greet{name: text} [
    return "Hello, " || name;
];

operator main{} [];
```

```trendy,error
operator sign{n: integer}: text [
    [
        var sign := "positive";
        if n < 0 then [
            return "negative";
        ];
        sign
    ]
];

operator main{} [];
```

```trendy,error
operator sign{n: integer}: text [
    var sign := "positive";
    while n < 0 loop [
        return "negative";
    ];
    sign
];

operator main{} [];
```

```trendy,error
operator sign{n: integer}: text [
    warn failure{message: "no sign yet"};
    "positive"
];

operator main{} [];
```

End the body with its value, in an operator with a result type:

```trendy
operator double{x: integer}: integer [
    var doubled := x * 2;
    doubled
];

operator greeting{name: text}: text [
    "Hello, " || name
];

operator sign{n: integer}: text [
    if n < 0 then "negative" else "positive"
];

operator described{n: integer}: text [
    "a " || [
        var sign := "positive";
        if n < 0 then [
            sign := "negative";
        ];
        sign
    ] || " number"
];

operator digits{n: integer}: integer [
    var left := n;
    var count := 1;
    while left >= 10 loop [
        left := left div 10;
        count := count + 1;
    ];
    count
];

operator main{} [
    call debug_value{v: greeting{name: "Amara"}};
];
```
