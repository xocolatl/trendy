# E0109: missing attribute

A tuple value must have every attribute of its declared type, because a
tuple's type is its heading: the full set of attribute names and types. The
fix adds the missing attribute with its type's default value.

```trendy,error
var point: tuple { x: rational, y: rational } := tuple { x: 1.0 };

operator main{} [];
```

Give every attribute a value:

```trendy
var point: tuple { x: rational, y: rational } := tuple { x: 1.0, y: 0.0 };

operator main{} [];
```
