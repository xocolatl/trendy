# R0006: tuple in common in a disjoint union

`r d_union s` is `r union s` where the operands have no tuple in common.
It states that they are disjoint, so a tuple in both is an error rather
than being merged into one, as `union` would. Use it where a shared
tuple would mean a mistake, such as when combining parts that should
partition a whole.

When the relations are known while compiling, a tuple they share is
reported there, naming it:

```trendy,error
var born := relation { { name: "Ada" }, { name: "Édouard" } };
var listed := relation { { name: "Ada" }, { name: "Wangari" } };
var everyone := born d_union listed;

operator main{} [];
```

When a relation is known only when the program runs, the program stops
instead, writing `error[R0006]: the operands of d_union have a tuple in
common` to stderr and exiting with status 1.

If tuples in common are fine, write `union`; otherwise, remove them from
one operand first:

```trendy
var born := relation { { name: "Ada" }, { name: "Édouard" } };
var listed := relation { { name: "Ada" }, { name: "Wangari" } };
var everyone := born union listed;
var distinct := born d_union (listed minus born);

operator main{} [];
```
