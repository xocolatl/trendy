# A0034: a read-only operator that changes something

A read-only operator changes nothing: invoking it updates no variable, as
*The Third Manifesto*'s RM Prescription 3 requires. Its body is one
`return`, of a value computed from its parameters and the variables it
reads. So it can't assign a variable, and it can't `call` an operator, not
even `debug_value`: sema evaluates a call when its arguments are known
when compiling, and evaluating it must never change what a program does.

```trendy,error
var calls := 0;

operator double{x: integer}: integer [
    calls := calls + 1;
    return x * 2;
];

operator main{} [];
```

Nor can it declare a local variable, so far: compute the value in the
`return`.

```trendy,error
operator double{x: integer}: integer [
    var doubled := x * 2;
    return doubled;
];

operator main{} [];
```

To change something, write an update operator, without a result type,
and invoke it with `call`; keep the read-only one for the value:

```trendy
var calls := 0;

operator double{x: integer}: integer [
    return x * 2;
];

operator count_call{} [
    calls := calls + 1;
];

operator main{} [
    call count_call{};
    call debug_value{v: double{x: 21}};
];
```
