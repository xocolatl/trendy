# A0034: a read-only operator that changes something

A read-only operator changes nothing: invoking it updates no variable but
its own local ones, as *The Third Manifesto*'s RM Prescription 3 requires.
Its value is computed from its arguments alone (A0050). So
it can't assign a variable of the program's, and it can't `call` an
operator, not even `debug_value`: sema evaluates a call when its arguments
are known when compiling, and evaluating it must never change what a
program does.

```trendy,error
var calls := 0;

operator double{x: integer}: integer [
    calls := calls + 1;
    x * 2
];

operator main{} [];
```

A value block changes nothing either, but its own local variables:

```trendy,error
var calls := 0;

operator main{} [
    call debug_value{v: [
        var doubled := 21 * 2;
        calls := calls + 1;
        doubled
    ]};
];
```

To compute a value in steps, assign local variables of the operator's own,
or of a value block's.
To change something, write an update operator, without a result type, and
invoke it with `call`; keep the read-only one for the value:

```trendy
var calls := 0;

operator double{x: integer}: integer [
    var doubled := x;
    doubled := doubled * 2;
    doubled
];

operator count_call{} [
    calls := calls + 1;
];

operator main{} [
    call count_call{};
    call debug_value{v: double{x: 21}};
];
```
