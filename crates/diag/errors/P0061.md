# P0061: malformed literal of bytes

A byte is two hexadecimal digits between `x'` and `'`, and an array of bytes is pairs
of them between `x"` and `"`, an underscore between any two digits. The digits are of
either case, and a value is written in lowercase:

```trendy
var low := x'7f';
var signature := x"dead_beef";
var nothing := x"";

operator main{} [];
```

Single quotes hold one, as they hold one character, so SQL's `x'dead'`, of any number
of bytes, is written in double quotes here:

```trendy,error
var signature := x'dead';

operator main{} [];
```

A byte has two digits, so an odd number of them is an error, with no fix, since the
missing digit could be any:

```trendy,error
var low := x'7';

operator main{} [];
```

SQL's `X'7F'` starts with a lowercase `x` here, and Python's and Rust's `b"ab"` is
written as its bytes, `x"6162"`:

```trendy,error
var greeting := b"ab";

operator main{} [];
```
