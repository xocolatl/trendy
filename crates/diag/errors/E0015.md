# E0015: chained comparison

Comparisons don't chain. In mathematics `a < b < c` means both `a < b` and
`b < c`, and some languages read it that way; others compare the boolean
`a < b` with `c`, which is almost never meant. trendy does neither, and
reports it. The fix compares the middle operand twice.

```trendy,error
var a := 1;
var b := 2;
var c := 3;
var ordered := a < b < c;

operator main{} [];
```

Write both comparisons, joined by `and`:

```trendy
var a := 1;
var b := 2;
var c := 3;
var ordered := a < b and b < c;

operator main{} [];
```

To compare the result of a comparison, which is a boolean, parenthesize it:
`(a < b) = (c < d)`.
