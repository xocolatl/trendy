# A0061: a union type has no selector

A union type with no possible representation of its own, a dummy type,
has no selector: each of its values is a value of one of its subtypes,
selected by that subtype's selector (*Type Inheritance and Relational
Theory*, chapter 12):

```trendy,error
type plane_figure union;

type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

var lake := plane_figure{a: 3e0, b: 2e0};

operator main{} [];
```

When the components named are those of one subtype's possible
representation, as `a` and `b` are an ellipse's, the fix selects that
subtype's value:

```trendy
type plane_figure union;

type ellipse is plane_figure { { a: approximate, b: approximate } };
type polygon is plane_figure { { corners: integer } };

var lake := ellipse{a: 3e0, b: 2e0};

operator main{} [];
```
