# A0021: cyclic initial values

Variables' initial values can refer to other variables, in any order, and are
evaluated before the program runs, each after the ones it refers to. When
variables refer to each other in a cycle, there is no order to evaluate them
in. The error lists the variables in the cycle, with a label at each
reference.

```trendy,error
var a := b;
var b := a;

operator main{} [];
```

An initial value that calls a read-only operator refers to the variables
the operator reads, which are evaluated first, so a cycle can go through
an operator:

```trendy,error
var total := sum_to{n: 3};

operator sum_to{n: integer}: integer [
    return total + n;
];

operator main{} [];
```

Give one of them a value that doesn't depend on the other:

```trendy
var a := true;
var b := a;
var base := 10;
var total := sum_to{n: 3};

operator sum_to{n: integer}: integer [
    return base + n;
];

operator main{} [];
```
