# A0021: cyclic initial values

Variables' initial values can refer to other variables, in any order, and are
evaluated before the program runs, each after the ones it refers to. When
variables refer to each other in a cycle, there is no order to evaluate them
in. The error lists the variables in the cycle.

```trendy,error
var a := b;
var b := a;

operator main{} [];
```

Give one of them a value that doesn't depend on the other:

```trendy
var a := true;
var b := a;

operator main{} [];
```
