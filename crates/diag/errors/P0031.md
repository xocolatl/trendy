# P0031: a body's value

A read-only operator's body declares and assigns its local variables, if
it has any, then ends with its value: an expression, without `;`, as in
Rust, and as Tutorial D's `WITH … : exp` ends with its expression. Only
the last item is the value; an expression before other statements is not a
statement. `return` is for leaving an operator early, so a body's value
written as other languages write it, `return x;`, is fixed to `x`, and a
`;` after the value is deleted.

```trendy,error
operator double{x: integer}: integer [
    return x * 2;
];

operator main{} [];
```

```trendy,error
operator double{x: integer}: integer [
    var doubled := x * 2;
    doubled;
];

operator main{} [];
```

```trendy,error
operator double{x: integer}: integer [
    x * 2;
    var unused := 1;
    x * 2
];

operator main{} [];
```

End the body with the value alone:

```trendy
operator double{x: integer}: integer [
    var doubled := x * 2;
    doubled
];

operator main{} [];
```
