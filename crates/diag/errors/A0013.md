# A0013: built-in or kind in a program

`builtin operator` declares an operator that the compiler implements. Those
declarations belong to the units that come with the compiler, which are
part of it: the prelude, which every unit sees, and the others, which a
unit uses, as it does `trendy.files` for `load_csv`. So a program never
declares built-ins itself: it can call `debug_value` directly. To define an
operator of your own, give it a body.
So does a kind: it says what its types must have, `<`, or `+` and `*`,
operators only the compiler gives. A type of the program's own is of a
kind when it has what the kind requires: `ordered`, when its braces give
it an order.

```trendy,error
builtin operator show{v: integer};

operator main{} [];
```

```trendy,error
kind sortable { < };

operator main{} [];
```

Define the operator with a body instead, and use the prelude's kinds:

```trendy
operator show{v: integer} [
    call debug_value{v: v};
];

operator before{a: T, b: T}: boolean types { T: any ordered } [
    a < b
];

operator main{} [];
```
