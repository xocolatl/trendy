# A0013: built-in or kind outside the prelude

`builtin operator` declares an operator that the compiler implements. Those
declarations belong to the prelude, which is part of the compiler and is
always in scope, so a program never declares built-ins itself: it can call
`debug_value` directly. To define an operator of your own, give it a body.
So does a kind: its types are those that declare it, as the prelude's
built-in types do, and a program can't declare a type, so a kind of its
own would have none.

```trendy,error
builtin operator show{v: integer};

operator main{} [];
```

```trendy,error
kind sortable { < };

operator main{} [];
```

Define the operator with a body instead, and use the prelude's kinds:

```trendy
operator show{v: integer} [
    call debug_value{v: v};
];

operator before{a: T, b: T}: boolean types { T: any ordered } [
    return a < b;
];

operator main{} [];
```
