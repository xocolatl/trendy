# A0024: attribute already exists

A tuple's or relation's attributes are a set, so each name can appear only
once. A `rename` whose new name is already taken, by an attribute that
isn't itself renamed away, or by another renaming's new name, would leave
two attributes with one name, and so would an `extend` that adds an
attribute the operand already has, or a `group` or a `wrap` whose new
attribute has the name of one it keeps (a name it gathers is free), or an
`ungroup` or an `unwrap` that gives an attribute named like one the
result keeps, or like one another ungrouped relation or unwrapped tuple
gives, or a load of an array into a relation whose `numbered n` names an
attribute the elements' tuples have, or the one `as x` names.

```trendy,error
var teams := relation { { name: "core", members: relation { { name: "Ada" } } } };
var memberships := teams ungroup {members};

operator main{} [];
```

```trendy,error
var births := relation { { name: "Ada", place: "London" } };
var by_place := births group { place := {name} };

operator main{} [];
```


```trendy,error
var addr := tuple { city: "Paris", district: "Louvre" };
var moved := addr rename {city as district};

operator main{} [];
```

`extend` adds attributes, so each new one needs a name the operand doesn't
have. When every attribute an `extend` names exists, the fix is `replace`,
which gives existing attributes new values:

```trendy,error
var item := tuple { name: "tea", price: 3 };
var doubled := item extend { price := price * 2 };

operator main{} [];
```

```trendy,error
var stops := array [tuple { city: "Lyon", n: 2 }, tuple { city: "Dijon", n: 1 }];

operator main{} [
    var route: relation { city: text, n: integer };
    load route from stops numbered n;
];
```

Choose a name that's free, or rename the other attribute too, since all the
renamings of one `rename` happen at once. To compute a new value for an
attribute, use `replace`; to change its type too, add it under another
name, then remove the old one and rename the new:

```trendy
var addr := tuple { city: "Paris", district: "Louvre" };
var moved := addr rename {city as municipality};
var swapped := addr rename {city as district, district as city};
var item := tuple { name: "tea", price: 3 };
var doubled := item replace { price := price * 2 };
var priced := item extend { new_price := tuple { amount: price, currency: "EUR" } } remove {price} rename {new_price as price};
var teams := relation { { name: "core", members: relation { { name: "Ada" } } } };
var memberships := teams rename {name as team} ungroup {members};
var stops := array [tuple { city: "Lyon", n: 2 }, tuple { city: "Dijon", n: 1 }];

operator main{} [
    var route: relation { city: text, n: integer, at: integer };
    load route from stops numbered at;
];
```
