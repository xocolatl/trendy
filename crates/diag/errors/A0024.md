# A0024: attribute already exists

A tuple's or relation's attributes are a set, so each name can appear only
once. A `rename` whose new name is already taken, by an attribute that
isn't itself renamed away, or by another renaming's new name, would leave
two attributes with one name, and so would an `extend` that adds an
attribute the operand already has.

```trendy,error
var addr := tuple { city: "Paris", district: "Louvre" };
var moved := addr rename {city as district};

operator main{} [];
```

`extend` adds attributes, so each new one needs a name the operand doesn't
have:

```trendy,error
var item := tuple { name: "tea", price: 3 };
var doubled := item extend { price := price * 2 };

operator main{} [];
```

Choose a name that's free, or rename the other attribute too, since all the
renamings of one `rename` happen at once. To compute a new value for an
attribute, add it under another name, then remove the old one and rename
the new:

```trendy
var addr := tuple { city: "Paris", district: "Louvre" };
var moved := addr rename {city as municipality};
var swapped := addr rename {city as district, district as city};
var item := tuple { name: "tea", price: 3 };
var doubled := item extend { new_price := price * 2 } remove {price} rename {new_price as price};

operator main{} [];
```
