# P0054: `tclose` written before its operand

`tclose` follows the relation it closes, as the other relational
operators that take one relation do, so that it reads in the order it
applies: `flows tclose where to = "Nile"` closes `flows`, then restricts
the closure. Tutorial D's `TCLOSE r` (TTM, chapter 5) puts it first, and
is fixed to `r tclose`, with the operand in parentheses kept as written:

```trendy,error
var flows := relation {
    { from: "Kagera", to: "Victoria" },
    { from: "Victoria", to: "White Nile" },
    { from: "White Nile", to: "Nile" },
    { from: "Blue Nile", to: "Nile" },
};
var reached := TCLOSE flows;
var sources := tclose (flows where from <> "Blue Nile");

operator main{} [];
```
