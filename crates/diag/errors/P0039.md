# P0039: a type's components without braces of their own

A type's declaration holds its possible representation, the components
a value of the type can be written with, in braces of their own inside
the type's: `type celsius { { degrees: approximate } };`. The outer
braces are what the declaration says of the type, and the inner ones one
possible representation of its values (*The Third Manifesto*, RM
Prescription 4). Components written straight inside the type's braces,
as a heading's attributes are, or after Tutorial D's `POSSREP`, are
reported:

```trendy,error
type celsius { degrees: approximate };

operator main{} [];
```

```trendy,error
type celsius POSSREP { degrees: approximate };

operator main{} [];
```

Put the components in braces of their own:

```trendy
type celsius { { degrees: approximate } };

operator main{} [];
```
